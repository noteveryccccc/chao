# 信息系统监理师 - 第51次学习（2026-08-28）

## 今日核心概念

### 1. 监理"四控两管一协调"总框架
定义：信息系统工程监理工作的核心职责框架，规定监理工作的七大业务领域，是监理师考试最核心的总纲性概念。
关键要点：
- **四控**：质量控制、进度控制、投资控制、变更控制（变更控制是信息系统监理特有，与建筑工程监理差异最大）
- **两管**：合同管理、信息管理（文档与资料管理）
- **一协调**：组织协调（业主/承包商/监理三方+设备供应商+外协单位）
- **相互关系**：质量是根本，进度是保证，投资是约束，变更贯穿四控，两管是支撑，协调是手段
- **应用原则**：四控两管一协调必须同时部署，不可偏废；任一环节失控将导致整体目标无法实现
- **考频**：案例分析题每年必考"四控两管一协调"的辨析与综合应用，需牢记每个维度的核心方法

### 2. 质量控制的方法体系（七种基本工具+新老七工具）
定义：信息系统工程质量控制的方法论集合，是监理开展质量监督、检查、评价的技术手段，是案例分析最常引用的工具集。
关键要点：
- **老七工具（常用）**：因果图（鱼骨图，找原因）、流程图（工序流程，找环节）、核对单（Checklist，事前防漏）、帕累托图（80/20法则，抓主要缺陷）、直方图（数据分布，看离散）、控制图（工序稳定性，判稳态）、散点图（两变量相关，看回归）
- **新七工具（管理）**：亲和图（归纳问题）、关联图（多因素关系）、树状图（层次展开）、矩阵图（行列交叉分析）、优先矩阵（评分排序）、过程决策程序图PDPC（应急方案）、活动网络图（统筹规划）
- **监理应用场景**：核对单用于开工前检查+隐蔽工程验收；因果图用于质量问题分析；控制图用于过程监控；帕累托图用于缺陷分级
- **七工具选择**：问题原因→因果图；数据分布→直方图；工序稳定→控制图；主次矛盾→帕累托图；流程问题→流程图；相关关系→散点图；防遗漏→核对单

### 3. 质量控制点的三类设置（W点/H点/S点）
定义：监理对承包商施工过程实施质量控制的关键见证点，根据重要程度分为见证点、停工待检点、旁站点三类，是过程质量控制的核心机制。
关键要点：
- **W点（Witness Point见证点）**：监理工程师到场见证但不必然停工，承包商在该工序完成后通知监理验收（如一般隐蔽工程、阶段性成果）
- **H点（Hold Point停工待检点）**：必须经监理工程师到场检查签字后才能进入下一道工序，未经签字认可不得擅自继续（如关键模块测试、安全功能验证、阶段性验收）
- **S点（Surveillance Point旁站点）**：监理工程师在施工关键环节全过程旁站监督，记录施工过程（如机房设备安装、网络核心节点调试、数据迁移操作）
- **设置原则**：关键工序设H点；重要工序设S点；一般工序设W点；承包商提前24小时书面通知监理
- **监理响应时限**：H点监理应在约定时间（通常4-8小时）内到场验收，未到场视为认可；S点监理必须全程在场
- **常见错误**：W点误用为H点→监理不必要停工→影响进度；H点误用为W点→监理不到位→留下质量隐患

### 4. 进度控制的方法体系（甘特图+网络图+关键路径+挣值分析）
定义：监理对工程进度实施监控的方法论集合，是确保按期完工的核心手段，需结合定性分析与定量计算。
关键要点：
- **甘特图（Gantt Chart）**：横道图，按时间轴展示任务开始/结束/并行关系，直观但难反映任务依赖
- **网络图（Network Diagram）**：节点（ADM）或箭线（AOA）表示任务及其逻辑依赖，分为PDM（紧前关系图）和ADM（箭线图）
- **关键路径法（Critical Path Method CPM）**：网络图中最长路径，决定项目最短完工期，关键路径上的活动延期将直接导致项目延期
- **关键路径计算**：正推算最早开始ES/最早完成EF；逆推算最迟开始LS/最迟完成LF；总时差TF=LS-ES；自由时差FF=紧后ES-本活动EF
- **挣值分析（EVM）**：三个参数PV（计划值）EV（挣值）AC（实际成本）；四个指标SV=EV-PV（进度偏差）/CV=EV-AC（成本偏差）/SPI=EV/PV/CPI=EV/AC
- **监理进度控制流程**：审批总进度计划→审批月度/周计划→检查实际进度→偏差分析（SV/SPI）→纠偏措施（赶工/快速跟进/资源调整）→签认进度款

### 5. 监理组织协调机制（三方协调+会议制度+沟通渠道）
定义：监理为协调业主、承包商及第三方关系所建立的常态化工作机制，是"一协调"的核心实现形式。
关键要点：
- **三方关系**：业主（建设单位/投资方）、承包商（承建单位/中标方）、监理（独立第三方）
- **监理独立性：监理不隶属于任何一方，按合同与法规独立执业，业主通过监理合同授权，承包商通过施工合同接受监理
- **三类协调会议**：第一次工地会议（开工前，介绍各方人员+确立工作流程）、工地例会（每周/双周例会，监理主持）、专题协调会（针对重大问题临时召开）
- **会议六要素**：会议通知（提前48小时）+会议签到+会议记录+会议纪要（监理起草+三方会签）+会议决议+落实跟踪
- **沟通渠道**：书面沟通（监理通知/监理工作联系单/监理日报/月报为主要载体）+口头沟通（重要事项必须书面确认）
- **协调原则**：公正独立、依据合同、证据充分、注重实效，不得越权调解法律纠纷（引导走仲裁/诉讼）

## 案例分析题

**题目**：
某市"智慧政务"综合平台建设项目，合同价5800万元，工期18个月。监理单位在监理过程中发生以下事件：
**事件1（质量控制）**：需求分析阶段，监理工程师审查发现承包商提交的《需求规格说明书》存在严重缺陷（核心业务需求模糊、用例缺失30%、验收标准未量化）。监理工程师签发《监理通知单》要求整改，承包商3周后才提交修订版本，且仍存在关键问题。
**事件2（进度控制）**：施工第8个月，检查发现网络子系统进度严重滞后：PV=1200万元，EV=900万元，AC=1050万元。项目已批准工期不变。
**事件3（变更控制）**：业主提出新增"区块链电子证照"模块需求，要求增加预算200万元、工期延长2个月。承包商提交《变更申请单》，监理工程师未进行变更影响评估就直接签字同意。
**事件4（投资控制）**：第10个月承包商申请支付进度款500万元，监理工程师审查发现累计完成产值仅420万元（按合同约定的里程碑付款比例核算）。
**事件5（协调机制）**：项目实施过程中，业主与承包商就某项需求变更的责任归属发生激烈争议，监理工程师以"中立调解人"身份出具书面调解意见，要求业主承担全部费用。承包商不服，拒绝执行。

问题：
1. 事件1中监理对需求规格说明书的审查属于质量控制的哪个环节？应依据哪个国家标准？监理处理流程存在什么问题？
2. 事件2中进度偏差如何分析？应采取哪些纠偏措施？请列出挣值分析的计算过程。
3. 事件3中监理工程师的变更签字是否合规？正确的变更控制流程是什么？
4. 事件4中监理应如何处理进度款支付？依据合同约定的付款条件如何审查？
5. 事件5中监理的"中立调解人"角色定位是否正确？监理协调应遵循什么原则？

**参考答案**：

**问题1（事件1质量控制分析）**：
- 审查环节：属于"质量预控"环节，是事前控制（事前预防），发生在产品/成果形成前，对投入资源（需求规格文档）进行审查
- 依据标准：GB/T 19668.5《软件工程监理》对需求分析阶段监理工作的具体要求（需求完整性、明确性、可测试性、可追溯性四性原则）
- 监理处理流程问题：
  ① 监理签发《监理通知单》正确，但未明确整改期限（应明确最长整改期+逾期处罚条款）
  ② 整改跟踪不到位：3周后承包商才提交修订版本，监理未实施中间跟踪+未升级处理（应视严重程度签发《工程暂停令》）
  ③ 修订版本仍存在关键问题，监理未再次明确指出问题清单+未要求二次评审
  ④ 未对需求缺陷可能导致的后续影响（设计/开发/测试连锁问题）做风险评估
- 正确做法：签发《监理通知单》明确整改要求+整改期限+逾期处罚→中间跟踪检查→承包商提交修订版后二次审查→若仍不合格升级签发《工程暂停令》并报业主→抄送行业协会计入承包商信用档案

**问题2（事件2进度偏差分析）**：
- 计算过程：
  - SV（进度偏差）= EV - PV = 900 - 1200 = -300万元（负值，进度滞后）
  - CV（成本偏差）= EV - AC = 900 - 1050 = -150万元（负值，成本超支）
  - SPI（进度绩效指数）= EV / PV = 900 / 1200 = 0.75（<1，进度滞后）
  - CPI（成本绩效指数）= EV / AC = 900 / 1050 ≈ 0.857（<1，成本超支）
- 进度状态判定：进度严重滞后（SPI=0.75，仅完成计划的75%）+成本超支（成本绩效偏低）
- 纠偏措施（按优先级）：
  ① **赶工（Crashing）**：增加资源（人力/设备）压缩关键路径上的活动工期，需评估成本
  ② **快速跟进（Fast-tracking）**：并行施工原顺序任务（如设计与编码并行），需评估风险
  ③ **资源调配**：从非关键路径调资源到关键路径
  ④ **范围调整**：与业主协商缩减非关键需求，释放工期
  ⑤ **技术方案优化**：承包商提出技术方案优化（如复用已有模块）
- 监理应签发《监理通知单》要求承包商提交《进度纠偏计划》→审批纠偏措施可行性→跟踪执行效果

**问题3（事件3变更控制分析）**：
- 监理签字不合规：
  ① 未做变更影响评估：未评估对进度（延长2月）、投资（增加200万）、质量（区块链技术风险）、范围（基线偏离）的影响
  ② 未走变更控制程序：变更必须经提出→评估→评审→批准→实施→验证六步
  ③ 监理越权：监理无权直接同意变更费用和工期调整（属业主决策权范围）
  ④ 未签发任何变更文件：变更必须形成《工程变更单》（CCB变更控制委员会签认）作为合同补充
- 正确变更控制流程（CCB五步+验证）：
  ① **变更申请**：变更提出方（业主/承包商/监理）书面提交《变更申请单》说明变更理由
  ② **变更评估**：监理组织评估变更对四控的影响（进度/投资/质量/范围），形成《变更影响评估报告》
  ③ **变更评审**：提交变更控制委员会（CCB，业主+监理+设计代表+必要时承包商）评审
  ④ **变更批准**：CCB决策（批准/有条件批准/拒绝），形成《工程变更单》（业主签认+三方会签）
  ⑤ **变更实施**：承包商按变更单实施，监理跟踪验证
  ⑥ **变更验证**：变更实施完成后，监理组织验收并签发《变更验收报告》，归档入合同补充协议
- 监理在此事件中应承担程序违规的失职责任，可能被业主追究违约责任

**问题4（事件4投资控制分析）**：
- 监理处理依据：合同约定的里程碑付款比例（如完成产值达合同价XX%按XX%支付）+ 已签认的《工程进度款支付证书》
- 审查流程：
  ① 审查承包商提交的《进度款支付申请》+附件（已完成工程量清单+产值计算表）
  ② 监理现场核实实际完成工作量（与监理日志、监理月报、现场照片交叉验证）
  ③ 计算应付进度款：应付金额 = 累计完成产值 × 合同约定的付款比例 - 累计已支付 - 扣留质保金 - 其他扣款
- 本案处理：
  - 承包商申报500万元，监理审核实际完成产值仅420万元
  - 应按合同约定的付款比例核算实际应付金额（如合同约定70%比例，则应付=420×70%=294万元）
  - 签发《工程进度款支付证书》按实际应付金额支付
  - 驳回多报部分（500-294=206万元），退回《支付申请》要求承包商修正后重新申报
- 监理依据：GB/T 19668系列中关于投资控制的具体条款+《建设工程价款结算暂行办法》+施工合同约定的付款条款

**问题5（事件5协调机制分析）**：
- 监理角色定位不正确：
  ① 监理不是"中立调解人"，监理是"独立的第三方"，代表业主利益（依据监理合同授权）
  ② 监理无权要求任何一方承担全部费用（费用承担涉及合同变更，需CCB批准）
  ③ 监理出具书面调解意见要求"业主承担全部费用"超越监理权限（监理只能提建议，不能裁决）
- 正确做法：
  ① 监理应出具《监理工作联系单》客观陈述事实+各方观点+监理意见（仅作为参考）
  ② 建议双方依据合同争议解决条款处理：先协商（30天）→ 调解（如需）→ 仲裁或诉讼
  ③ 监理可作为专家证人配合仲裁/诉讼，不得强制任何一方执行监理意见
  ④ 监理应避免介入合同纠纷实质判断（避免越权+避免成为被告）
- 监理协调原则（六原则）：
  ① 公正原则（不偏袒任何一方，依据合同与事实）
  ② 独立原则（不受任何一方不当干预）
  ③ 证据原则（所有协调意见必须以书面证据+合同条款为依据）
  ④ 书面原则（重要事项必须形成书面文件，签字确认）
  ⑤ 时效原则（及时响应，避免小问题拖成大问题）
  ⑥ 边界原则（不越权调解合同纠纷，建议走争议解决程序）

**踩分要点**：
- 质量预控要点：需求审查=事前控制；依据GB/T 19668.5；整改需明确期限+升级处理（高频考点）
- 挣值分析要点：SV=EV-PV/CV=EV-AC/SPI=EV/PV/CPI=EV/AC四个公式必须熟练计算（每年必考计算题）
- 变更控制要点：CCB五步流程（申请→评估→评审→批准→实施→验证）；监理无权直接批准费用工期（送分题）
- 投资控制要点：付款审核=实际产值×合同比例-累计已付-扣款（必考点）
- 协调边界要点：监理≠调解人；监理不裁决费用归属；争议引导走仲裁诉讼（核心考点）

## 记忆口诀

**四控两管一协调口诀**：质量进度投资变、合同信息两管严、组织协调一贯穿、四控两管一协调缺一不可全部署。

**质量控制七工具口诀**：因果流程核对单、帕累直方控制散、老七工具过程控、新七工具管理用。

**三类控制点口诀**：W见证H停工S旁站、W签到场不必然停、H签不到不许动、S签全程不离场。

**关键路径口诀**：正推ES EF、逆推LS LF、总时差TF=LS-ES、自由时差FF=紧后ES减本EF。

**挣值分析四指标口诀**：SV=EV减PV、CV=EV减AC、SPI=EV除PV、CPI=EV除AC、SV负进滞CV负本超。

**变更控制六步口诀**：申请评估评审批、实施验证归档、CCB变更控制委员会、不经评审监理无权批。

**监理协调六原则口诀**：公正独立证据在、书面时效边界严、监理不是调解人、争议引导走仲裁。

**监理签字权限口诀**：总监合同重大签、专监专项日常签、监理员记录不签认、三要素齐全代签无效。
