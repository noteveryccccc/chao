## 今日核心概念

### 1. 监理进度控制总框架
定义：在合同工期内，运用审批、跟踪、检查、协调、纠偏等手段，对工程实施全过程进行时间维度管控，使工程按期或提前完成目标的监理活动。
关键要点：
- 三步走：事前编制进度计划（含里程碑、WBS、网络图、横道图）+ 事中跟踪检查（实际进度与计划对比、关键路径监控、进度偏差分析）+ 事后纠偏调整（赶工/并行/快速跟进/范围调整）
- 进度计划体系：总进度计划→年度计划→季度计划→月计划→周计划，五级分解、逐级细化、上保下、下保上
- 进度控制三工具：横道图（Gantt直观）、网络图（关键路径+逻辑关系）、S曲线（挣值+进度偏差可视化）
- 进度延期处理：监理审核延期申请→分析原因→区分责任（业主/承建/不可抗力）→批准或驳回→签发监理通知
- 监理不签发工程开工令，不得擅自批准延期，不得越权签发停工令（停工令须报建设单位批准）

### 2. 关键路径法CPM与网络计划技术
定义：通过绘制网络图，将工程活动按逻辑关系串联，计算每条路径总工期，找出决定总工期的关键活动序列（关键路径），并据此进行工期优化和资源调配的计划方法。
关键要点：
- 网络图四要素：节点（事件/里程碑）、箭线（活动/作业）、虚工作（逻辑关系不耗资源时间）、时差（活动可推迟不影响总工期）
- 时间参数六算：最早开始ES、最早完成EF、最迟开始LS、最迟完成LF、自由时差FF、总时差TF；总时差为零的连成关键路径
- 关键路径特征：路径最长、时差为零、活动延误即总工期延误；关键路径可能随进度变化而转移
- 工期优化四法：赶工（加资源压缩关键活动工期）、并行（顺序改并行）、快速跟进（设计施工搭接）、范围调整（缩减非关键功能）
- 监理应用：审核承建单位进度计划合理性→识别关键路径→重点监控关键活动→分析进度偏差对总工期影响

### 3. 进度计划审核要点
定义：监理工程师对承建单位提交的施工进度计划，从完整性、合理性、可执行性、合规性四个维度进行审查的活动，是进度事前控制的核心环节。
关键要点：
- 审核八要素：合同工期符合性、里程碑节点合理性、WBS分解粒度、工序逻辑关系、资源配置匹配、风险预留裕度、关键路径识别、报批程序合规
- 横道图审核：活动起止时间、持续时长、并行/串行关系、关键路径标识、里程碑节点
- 网络图审核：逻辑关系正确、虚工作使用合理、时间参数计算正确、关键路径标注清晰
- 资源曲线审核：人力/设备/资金投入曲线与进度匹配、无明显峰谷冲突
- 监理处置：审核通过签认意见→报建设单位备案→要求承建单位按计划执行→动态检查纠偏

### 4. 进度偏差分析与纠偏措施
定义：当实际进度偏离计划进度时，监理工程师通过对比分析、原因识别、责任判定，提出并监督纠偏措施落地，使工程回归计划轨道的监理活动。
关键要点：
- 偏差分析三参数：进度偏差SV=EV-PV（>0提前，<0拖期）、成本偏差CV=EV-AC、进度绩效指数SPI=EV/PV（>1提前）
- 偏差原因七类：业主原因（资金/场地/决策）、承建原因（人员/技术/管理）、设计原因（变更/缺陷）、监理原因（失职/失误）、供应商原因、自然原因、社会原因
- 责任判定四步：查阅监理记录→召开进度专题会→分析责任证据→形成书面责任认定意见
- 纠偏措施五类：组织措施（增人员/调组织）、管理措施（改流程/强协调）、技术措施（优方案/并行）、经济措施（奖罚/赶工费）、合同措施（索赔/变更）
- 纠偏跟踪：措施落实情况复查→效果评估→未达标二次纠偏→形成进度专题报告

### 5. 工程延期与工期索赔管理
定义：当工程发生非承建单位责任的事件，导致工期延误时，监理工程师依据合同约定审核延期申请，并协调工期与费用索赔的监理活动。
关键要点：
- 延期类型二类：可原谅延期（业主/不可抗力）+ 不可原谅延期（承建责任）；前者只批工期不批费用，后者既不批工期也不批费用
- 索赔三要素：事件真实（事实清楚）、责任清晰（非己方责任）、证据充分（书面记录、签证、影像）
- 索赔程序四步：28天内提出意向通知→详细资料和证明文件报送→监理审核事实和金额→业主最终批复
- 监理审核六查：查合同依据、查事件责任、查实际损失、查证据链、查时效性、查计算方法
- 反索赔：对承建单位的违约行为（如工期延误、质量缺陷），建设单位向承建单位提出的索赔，监理须公正审核

## 案例分析题

**题目**：
某市"智慧公安"信息化平台建设项目，合同工期18个月，合同价6800万元。承建单位按合同要求提交了经监理审核的总进度计划，明确了8个里程碑节点。项目建设进入第9个月时，发生以下事件：

事件一：因业主负责的机房场地延期交付2个月，导致承建单位网络设备到货后无法进场安装，承建单位提出工期顺延2个月并索赔窝工费用85万元。

事件二：监理工程师在审核月报时发现，本月计划完成软件编码工作量的20%，但实际仅完成12%，关键路径上的核心模块延期8天，承建单位未采取任何纠偏措施。

事件三：项目第10个月，承建单位以"应对业主新需求"为由，向监理提交了一份《项目进度计划调整方案》，拟将原定的网络部署与软件开发并行实施调整为串行实施，关键路径较原计划延长45天，总工期从原18个月调整为19.5个月。

事件四：项目第12个月，因罕见暴雨导致机房进水，部分已安装设备损坏，承建单位提出工期顺延15天并索赔设备维修及更换费用120万元。

问题：
1. 针对事件一，监理工程师应如何审核承建单位的工期顺延和费用索赔申请？请说明理由。
2. 针对事件二，监理工程师应采取哪些具体措施？关键路径延期8天是否必然导致总工期延期8天？
3. 针对事件三，监理工程师应如何处理承建单位提交的《项目进度计划调整方案》？该方案将并行改串行是否属于重大变更？
4. 针对事件四，监理工程师应如何审核工期顺延15天和费用索赔120万元的申请？罕见暴雨属于何种性质的延期事件？

**参考答案**：

问题1：
- 监理应审核三项：合同依据（合同中是否有业主按时提供场地的约定）、事件责任（场地延期确属业主责任）、证据链（场地延期书面通知、现场签证、影像资料）
- 工期顺延审核：场地延期2个月为客观事实，监理应批准工期顺延2个月
- 费用索赔审核：窝工费用需逐项审查——人员窝工费按实际人数×窝工天数×日工资标准核对；设备停滞费按租赁合同/折旧标准核对；管理费按比例分摊核对
- 监理处置：签发《工程延期审批表》报建设单位批准→费用索赔报建设单位审批→要求承建单位提供详细费用计算书和证明材料

问题2：
- 关键路径延期8天不一定导致总工期延期8天：若关键路径上该活动的总时差为0，则导致总工期延期8天；若总时差≥8天，则不影响总工期
- 监理具体措施：
  1. 签发《监理通知单》要求承建单位分析进度偏差原因并提交纠偏措施
  2. 召开进度专题协调会，要求承建单位调整资源投入
  3. 审查纠偏措施可行性：增派核心开发人员、加班赶工、并行开发非关键模块
  4. 下达《工程暂停令》（若情况严重）或《监理工程师通知单》，要求限期整改
  5. 持续监控关键路径活动，每周报送进度数据
  6. 偏差记录入监理月报向建设单位报告

问题3：
- 平行改串行属于重大变更判断：方案将关键路径延长45天，触及合同工期（18个月）实质改变，属于重大变更
- 监理处理程序：
  1. 审查变更合理性：业主是否真有"新需求"、为何会导致并行改串行、技术论证是否充分
  2. 退回报审：方案缺少业主需求变更文件、技术经济论证、费用影响测算，要求补正
  3. 重大变更须经建设单位、设计单位（如涉及）共同审批，监理无单方批准权
  4. 监理签发监理意见：不同意未经审批先实施；要求承建单位按原合同进度执行
  5. 若业主确需变更，则按变更程序办理：申请→审查→审批→实施→验收

问题4：
- 罕见暴雨属于不可抗力：依据合同不可抗力条款，通常既可顺延工期也可索赔费用（具体看合同约定）
- 工期顺延审核：
  1. 查证：气象部门暴雨证明、灾害发生记录、监理现场日志
  2. 核实实际影响：进水时长、清理恢复时间、设备维修周期
  3. 剔除承建单位自身原因：设备未妥善存放、未采取防护措施部分不予顺延
  4. 批复：合理工期顺延15天，若有扩大损失则核减
- 费用索赔审核：
  1. 设备维修费：保险公司赔付部分剔除；未投保部分按合同约定处理
  2. 设备更换费：核对损坏清单、报价单、原合同设备价格
  3. 监理要求承建单位提供：灾害证明、损失清单、费用计算依据、影像资料
  4. 监理审核后报建设单位审批

**踩分要点**：
- 关键路径延期≠总工期延期（看总时差），这是高频考点，必须强调"总时差为零才影响总工期"
- 平行改串行涉及关键路径延长45天+合同工期变动，必须识别为重大变更，按变更程序走
- 不可抗力的认定要看合同条款，监理处理不可抗力须区分工期和费用分别处理
- 索赔时效（28天意向通知）是必答要点，监理审核索赔必须检查时效性
- 监理职责边界：批准延期须报建设单位、签发停工令须报建设单位、重大变更须共同审批，监理无单方决定权

## 记忆口诀

1. **进度控制三步走**：事前计划编→事中跟踪查→事后纠偏调
2. **进度计划五级分解**：总→年→季→月→周，上保下、下保上
3. **关键路径三特征**：路径最长时差零，延误即拖总工期，路径可能转移
4. **偏差分析三参数**：SV=EV-PV，CV=EV-AC，SPI=EV/PV
5. **进度纠偏五措施**：组（织）管（理）技（术）经（济）合（同）
6. **延期三类判定**：业主原因可原谅（批工期+费用）、承建原因不原谅（不批工期不批费用）、不可抗力看合同（一般批工期看费用）
7. **索赔程序四步**：28天意向通知→详细资料报送→监理审核事实金额→业主最终批复
8. **进度监理三边界**：不签开工令、不擅批延期、不越权停工（停工须报业主）
9. **里程碑管理**：里程碑是合同刚性节点，监理须重点监控、零容忍延期
10. **横道图网络图**：横道直观看进度、网络算时差找关键、S曲线挣值可视化
