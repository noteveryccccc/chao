## 今日核心概念
### 1. 项目沟通管理
定义：确保项目信息的及时、适当生成、传递、存储、控制与最终处置，使干系人获得所需信息并达成一致。

关键要点：
- 沟通渠道数公式：N(N-1)/2（N人之间的沟通渠道数，如5人=10条，12人=66条）
- 三种沟通模型：互动式（即时双向，如会议/电话/即时通讯）、推式（单向，如邮件/报告/通知）、拉式（接收方主动获取，如网站/知识库/门户）
- 沟通矩阵：明确"谁在何时用什么方法向谁传递什么信息"（5W1H：谁/何事/何时/何法/何人/何因）
- 沟通障碍：编码/解码差异、噪声、信息过滤、媒介选择不当、文化差异
- 沟通有效性 = 发送方表达清晰 + 渠道通畅 + 接收方正确理解
- 会议类型：启动会、评审会、状态会、协调会、决策会，需有明确目标与产出

### 2. 项目干系人管理
定义：识别干系人、分析其权力与利益诉求、制定策略使其合理参与并有效管理，是项目成功的关键。

关键要点：
- 干系人识别：尽早识别、持续更新，用"干系人登记册"记录基本信息
- 权力/利益方格（四象限）：高权高利=重点管理；高权低利=令其满意；低权高利=随时告知；低权低利=监督
- 干系人参与程度五级：不知晓→反对→中立→支持→领导（从消极到积极五级递进）
- 管理策略：对核心干系人重点管理，对次要干系人随时告知，对反对者主动沟通化解
- 干系人登记册内容：基本信息+权力+利益+分类+初始评估+沟通策略
- 与沟通管理关系：干系人分析是沟通计划与沟通矩阵的基础

### 3. 项目资源管理与团队建设
定义：获取、管理项目团队资源，促进团队发展与协作、提升团队绩效。

关键要点：
- 获取资源：资源日历、资源分配、招募/谈判/激励，资源要可获取且匹配
- 团队发展五阶段（Tuckman模型）：形成→震荡→规范→成解→解散，震荡阶段冲突多属正常
- 冲突管理五方法（Thomas-Kilmann）：合作/解决问题（赢-赢）、妥协/分庭（各让一步）、缓和/包容（以和为贵）、强迫/指挥（赢-输）、撤退/回避（输-输）
- 激励理论：马斯洛需求层次、麦格雷X/Y理论、赫茨双因素理论、期望理论
- 资源平衡（平滑）：平衡资源使用避免过度分配；资源平滑：在关键链上控制进度
- 虚拟团队：借助通信技术跨地域协作，沟通成本与信任建立是关键

### 4. 项目采购管理
定义：从项目团队外部采购产品、服务或成果的过程，含规划、实施与控制三环节。

关键要点：
- 三种合同类型：
  - 固定总价合同（FFP）：范围明确、风险在卖方，买方成本确定
  - 成本补偿合同（CP）：买方承担成本风险，分成本加固定费(CPFF)/成本加激励费(CPIF)/成本加百分比(CP%)
  - 计时计料合同（T&M）：按工时与费率，适用于工作范围不确定
- 自制/外购决策（Make-or-Buy）：成本、能力、风险、战略、时间五要素
- 采购三过程：采购规划（编制采购管理计划+工作说明书SOW）→实施采购（供方选择）→控制采购
- 工作说明书（SOW）：明确要采购的产品/服务/成果的具体要求
- 验收：买方对交付物按SOW与合同标准进行检验，合格方可接受

### 5. 项目风险管理
定义：识别、分析并应对项目风险，提高正面风险（机会）概率、降低负面风险（威胁）影响。

关键要点：
- 风险管理六过程：识别→定性分析→定量分析→规划应对→实施应对→监控
- 风险登记册：风险描述+原因+影响+概率+应对策略+责任人
- 概率×影响矩阵：概率（高/中/低）×影响（高/中/低）定风险等级
- 消极风险（威胁）应对四策略：规避(Avoid)、转移(Transfer)、减轻(Mitigate)、接受(Accept)
- 积极风险（机会）应对四策略：开拓(Exploit)、分享(Share)、提高(Enhance)、接受(Accept)
- 风险储备：应急储备（应对已知-未知）、管理储备（应对未知-未知）
- 风险识别技术：德尔菲法、SWOT分析、检查表、头脑风暴、假设分析

## 案例分析题
**题目**：某市"智慧城管综合管理平台"建设项目，预算3600万元，工期20个月，涉及住建、城管、交通、环保4个委办局，由第三方监理及2家供应商参与。项目启动3个月后出现以下问题：

- 问题一：项目组成员12人，但周报显示沟通不畅、需求理解不一致、返工率高。
- 问题二：城管局是核心干系人，对进度高度关注；环保局对数据共享范围不满，频繁反对变更。
- 问题三：团队由5家单位组成，磨合半年仍冲突不断，进度滞后。
- 问题四：采购某供应商软件采用固定总价合同，但需求变化大，供应商要求加价，双方扯皮。
- 问题五：进度已滞后，但风险登记册仅列"技术风险"一项，无应对措施。

问题：
1. 针对问题一，请计算12人的沟通渠道数，分析沟通不畅的原因，并说明三种沟通模型的适用场景。
2. 针对问题二，请用权力/利益方格分析城管局和环保局，并说明不同干系人的管理策略。
3. 针对问题三，请说明Tuckman团队发展五阶段，并给出五种冲突管理方法的适用场景。
4. 针对问题四，请分析固定总价合同的适用场景与风险，说明为何本项目不宜用FFP，并建议更合适的合同类型。
5. 针对问题五，请说明风险管理六步流程，并给出消极风险与积极风险应对策略各两种。

**参考答案**：

1. 沟通渠道与模型：
   - 沟通渠道数 = N(N-1)/2 = 12×11/2 = 66条。渠道过多导致信息传递损耗、编码解码偏差、过滤
   - 沟通不畅原因：沟通渠道过多、媒介选择不当、信息过滤、缺乏沟通矩阵与沟通计划、干系人利益诉求不一致
   - 三种沟通模型适用：互动式（即时双向，会议/电话/即时通讯，适合决策与复杂问题讨论）、推式（单向，邮件/报告/通知，适合信息通知与状态报告）、拉式（接收方主动获取，知识库/门户/文档库，适合资料与自助查询）

2. 干系人分析与策略：
   - 城管局：高权高利=重点管理，持续沟通确保满意，定期汇报进度并主动协调
   - 环保局：若为高权低利=令其满意，定期沟通防止其转为反对；若数据共享涉及其核心利益则可能高权高利=重点管理
   - 管理策略：对核心干系人（城管局）重点管理、主动沟通；对次要干系人随时告知；对反对者（环保局）主动沟通化解分歧、明确其诉求与利益、纳入干系人登记册并制定针对性沟通策略

3. 团队建设与冲突管理：
   - Tuckman五阶段：形成（成员试探、依赖领导）→震荡（冲突频发、角色冲突）→规范（确立规则、协作顺畅）→成解（高效运作、绩效最佳）→解散（项目结束、团队解散）
   - 本项目处于震荡期，冲突多属正常，需加强引导与规则建立
   - 五种冲突管理方法适用：合作/解决问题（赢-赢，适用于复杂问题、双方都重要）、妥协/分庭（各让一步，适用于时间紧、双方势均力敌）、缓和/包容（以和为贵，适用于关系重要、问题次要）、强迫/指挥（赢-输，适用于紧急决策、领导权威）、撤退/回避（输-输，适用于问题琐碎、不值得投入）

4. 合同类型分析：
   - 固定总价合同（FFP）适用：范围明确、风险小、需求稳定，成本确定、风险在卖方
   - 本项目不宜FFP：需求变化大、范围不明确，FFP下卖方承担风险会抬高报价或降低质量，甚至违约，导致扯皮
   - 更合适合同：成本补偿合同（CPFF或CPIF，由买方承担成本风险，适合范围不确定）或计时计料合同（T&M，按工时与费率，适合工作范围不确定的开发类采购）
   - 建议：采用成本加激励费合同（CPIF）或计时计料合同，兼顾灵活性与成本可控，并设置成本上限与激励机制

5. 风险管理：
   - 六步流程：识别→定性分析（概率×影响矩阵）→定量分析（蒙特卡洛/EMV期望值）→规划应对→实施应对→监控
   - 消极风险（威胁）应对：规避（改变计划避免风险发生，如调整技术方案）、转移（外包或投保转移风险给第三方）、减轻（降低概率或影响，如增加测试）、接受（被动或主动接受风险）
   - 积极风险（机会）应对：开拓（确保机会实现，如优先采用新技术提升效率）、分享（与第三方合作共享机会，如联合开发共享收益）、提高（增加机会概率，如增加资源投入抓住窗口）、接受（等待机会发生）
   - 整改：补全风险登记册，列出技术、管理、商务、外部四类风险，每项配概率、影响、应对策略与责任人

**踩分要点**：
- 第1题：必算准66条渠道；三种沟通模型各写清适用场景；沟通不畅原因要答出"渠道过多+媒介不当+过滤+缺沟通矩阵"
- 第2题：权力/利益方格四象限要说全（重点/满意/告知/监督）；城管局重点管理、环保局令其满意，策略要对应
- 第3题：Tuckman五阶段顺序必须正确（形成→震荡→规范→成解→解散）；冲突五方法各配适用场景，漏方法扣分
- 第4题：FFP适用"范围明确、风险小"；本项目"需求变化大"不宜FFP；要建议CP（CPFF/CPIF）或T&M并说明理由
- 第5题：六步流程要完整；消极应对四策略、积极应对四策略各至少答两种；要补全风险登记册

## 记忆口诀
### 沟通渠道数口诀
**「N(N-1)除2，12人66条」**
- 渠道数 = N(N-1)/2
- 5人=10条，10人=45条，12人=66条
- 渠道越多越易损耗

### 沟通三模型口诀
**「互动双向推单向，拉式主动自己找」**
- 互动：即时双向（会议/电话/IM）
- 推：单向通知（邮件/报告）
- 拉：主动获取（知识库/门户）

### 干系人四象限口诀
**「高权高利重点管，高权低利令满意，低权高利随时告，低权低利仅监督」**
- 重点管理
- 令其满意
- 随时告知
- 监督

### 干系人五级口诀
**「不反中支领」**
- 不知晓
- 反对
- 中立
- 支持
- 领导
- 从消极到积极五级递进

### 团队五阶段口诀
**「形震规成解」**
- 形成（Forming）
- 震荡（Storming）
- 规范（Norming）
- 成解（Performing）
- 解散（Adjourning）

### 冲突五方法口诀
**「合妥缓强退」**
- 合作（赢-赢）
- 妥协（各让一步）
- 缓和（以和为贵）
- 强迫（赢-输）
- 撤退（输-输）

### 合同三类型口诀
**「固定成本计时料」**
- 固定总价（FFP）：范围明确
- 成本补偿（CP）：买方担成本风险
- 计时计料（T&M）：按工时费率

### 风险应对口诀
**「消极避转减接，积极开享提接」**
- 消极（威胁）：规避、转移、减轻、接受
- 积极（机会）：开拓、分享、提高、接受

### 风险管理六步口诀
**「识定性定量，应对实施监控」**
- 识别
- 定性分析（概率×影响）
- 定量分析（EMV/蒙特卡洛）
- 规划应对
- 实施应对
- 监控
