## 今日核心概念
### 1. 项目进度管理网络图绘制
定义：依据活动清单与逻辑关系，绘制项目进度网络图，确定活动先后依赖与关键路径的图形化方法。

关键要点：
- 网络图两大类型：PDM（前置图/单代号网络图，活动用方框表示，AOA双代号已较少使用）
- PDM四依赖关系：FS（结束-开始，最常用）、SS（开始-开始）、FF（结束-结束）、SF（开始-结束，少用）
- 网络图绘制原则：每节点有唯一编号、禁止环路、起点终点唯一、单代号网络无虚活动
- 关键路径：网络图中工期最长的路径，决定项目最短完工期，是进度压缩的核心对象
- 关键路径可有多条，但总浮动时间（Total Float）为零的活动组成的路径

### 2. 关键路径法（CPM）与总时差计算
定义：通过正向计算最早开始/最早结束，反向计算最迟开始/最迟结束，求解关键路径与时差的项目进度分析方法。

关键要点：
- 正向计算：ES（最早开始）= 紧前活动EF最大值；EF = ES + 工期
- 反向计算：LF（最迟结束）= 紧后活动LS最小值；LS = LF - 工期
- 总时差TF = LS - ES = LF - EF，正向反向任一为零即为关键活动
- 自由时差FF = 紧后活动ES - 本活动EF，不影响紧后最早开始
- 关键路径特征：所有活动TF=0；任意关键活动延期一天项目整体延期一天

### 3. 进度压缩与资源平衡技术
定义：在不缩减项目范围的前提下，通过特定技术压缩工期或平衡资源使用，解决进度冲突的方法集合。

关键要点：
- 赶工Crashing：在关键路径活动上追加资源（加班/加人或高成本资源），以成本换工期
- 快速跟进Fast Tracking：将原本串行的活动并行开展，以返工风险换工期
- 资源平衡Resource Leveling：调整进度使资源使用平滑，可能延长工期（改路径、不改工期）
- 资源平滑Resource Smoothing：只调整非关键活动使资源峰值不超过限值，不改关键路径、不延工期
- 选择准则：赶工适用关键路径上边际成本低的活动；快速跟进适用并行无强依赖的活动

### 4. 成本估算与预算编制
定义：估算项目活动所需成本，汇总形成成本基准，作为成本控制依据的全过程。

关键要点：
- 三种估算精度：粗略量级估算（-50%~+100%）、预算估算（-10%~+25%）、确定性估算（-5%~+10%）
- 估算方法：类比估算（自上而下，专家判断）、参数估算（数学模型）、三点估算（三点加权）
- 三点估算公式：期望工期 = (乐观 + 4×最可能 + 悲观) / 6；标准差 = (悲观 - 乐观) / 6
- 成本基准：经批准的、按时间分布的项目预算，是成本控制的依据，不含管理储备
- 管理储备vs应急储备：管理储备为未识别工作，应急储备为已识别风险，管理储备使用需变更程序

### 5. 成本控制与挣值管理（EVM）
定义：通过挣值三参数与四指标，对项目成本与进度进行综合测量、预测与纠偏的过程。

关键要点：
- 挣值三参数：PV（计划值）、EV（挣值/已完成工作的预算值）、AC（实际成本）
- 进度偏差SV = EV - PV；成本偏差CV = EV - AC
- 进度绩效指数SPI = EV/PV；成本绩效指数CPI = EV/AC
- 综合判断：CPI<1超支，SPI<1滞后；二者均<1双重失控
- 完工估算EAC = BAC / CPI（典型公式）；完工尚需估算ETC = EAC - AC

## 案例分析题
**题目**：某市人社局"智慧就业服务平台"项目工期12个月，预算800万元，项目进入第6个月时已花费500万元，完成了原计划8个月对应的工作量。监理工程师调取挣值数据发现：PV=480万、EV=400万、AC=500万。项目管理办公室要求必须按期完工且严控成本。

项目关键路径上"就业岗位匹配引擎开发"原计划3个月由Java团队独立完成，因引入Python算法团队需并行开发，原计划"接口联调"被压缩为2周并行启动。测试阶段发现核心模块缺陷率上升20%，项目经理提出三种应对方案：方案A引入第三方测试外包赶工；方案B延长每日工时至晚9点赶工；方案C增加2名高级开发人员驻场。同时项目还剩余"系统安全测评"与"等保三级测评"两项强制节点。

问题：
1. 请计算该项目当前CPI、SPI、SV、CV，并判断项目当前成本与进度状态；计算完工估算EAC与完工偏差VAC。
2. 接口联调压缩为2周并行启动属于赶工还是快速跟进？测试缺陷率上升20%的原因是什么？请给出至少3项质量保证改进措施。
3. 三个赶工方案A、B、C中，请选择最合适方案并说明理由；分析快速跟进对项目质量与成本的连锁影响。
4. 系统安全测评与等保三级测评属于何种过程？请说明两者区别与实施时点。

**参考答案**：

1. 挣值计算与判断：
   - CV = EV - AC = 400 - 500 = -100万（成本超支100万）
   - SV = EV - PV = 400 - 480 = -80万（进度滞后，折合工作价值80万）
   - CPI = EV/AC = 400/500 = 0.8（成本绩效差，每花1元只完成0.8元工作）
   - SPI = EV/PV = 400/480 ≈ 0.833（进度绩效差，完成计划83.3%工作）
   - EAC = BAC / CPI = 800 / 0.8 = 1000万（预计完工总成本1000万，超预算200万）
   - VAC = BAC - EAC = 800 - 1000 = -200万（完工时预计超支200万）
   - 状态判断：CPI<1且SPI<1双重失控，成本超支+进度滞后

2. 接口联调压缩方案与质量改进：
   - 属于快速跟进（Fast Tracking），不是赶工：把原串行的"接口联调"活动与"匹配引擎开发"改为并行启动，是通过并行压缩工期，符合快速跟进定义
   - 缺陷率上升原因：①并行导致联调不充分（接口未稳定就提测）；②Java与Python团队代码规范差异；③缺乏跨团队评审；④赶工压缩正常测试用例执行时间
   - 质量改进措施：①强制代码评审（至少2人交叉review）；②增加接口Mock测试与契约测试用例；③补充单元测试覆盖率至80%以上；④建立缺陷根因分析与每日回归机制

3. 赶工方案选择与连锁影响：
   - 推荐方案A（第三方测试外包）。理由：方案B延长工时边际效益递减且易致疲劳引入新缺陷；方案C追加高级人员成本高且需磨合；方案A借用外部专业测试资源提升质量且压缩工期，与当前缺陷率高发场景最匹配
   - 快速跟进连锁影响：①质量风险上升（接口未稳定就并行测试）；②返工成本上升（缺陷率+20%）；③团队协作成本上升（Java/Python跨技术栈沟通）；④风险储备被消耗（应急储备减少）；⑤最终BAC上升（项目总成本增加）

4. 安全测评与等保测评：
   - 属于项目监控过程组与收尾过程组的强制节点（也可视作质量控制与合规验证活动）
   - 系统安全测评：第三方测评机构依据GB/T 22239等标准对系统进行安全功能、性能测试，属信息系统整体安全验证
   - 等保三级测评：依据《网络安全法》与等保2.0要求，对定级为三级的系统实施等级保护测评，覆盖物理、网络、主机、应用、数据5个层面
   - 区别：系统安全测评侧重功能性能、等保测评侧重合规定级；实施时点均需在试运行前完成，建议在初验前完成测评与整改

**踩分要点**：
- 第1题：四个指标计算必须全对（CPI、SPI、CV、SV），并明确写出"双重失控"判定；EAC必须用BAC/CPI公式（非其他公式变体）
- 第2题：判断必须写"并行=快速跟进"，不能写"赶工"；质量原因要答到"接口未稳定"+"跨团队规范差异"；改进措施要具体可落地
- 第3题：方案选择要给出对比分析；连锁影响必须涵盖质量、返工、协作、储备、BAC五个维度至少四个
- 第4题：必答"等保2.0三级"+"五层五个层面"；区分系统安全测评与等保测评的合规视角；强调实施时点在初验前

## 记忆口诀
### PDM四依赖关系口诀
**「结束开始最常用，结束结束少开始，开始结束极罕用」**
- FS：最常用（约90%场景）
- SS：开始-开始
- FF：结束-结束
- SF：开始-结束（几乎不用）

### 关键路径判别口诀
**「路径最长时差零，组成即为关键径」**
- 关键路径=总时差为零的活动组成
- 网络图工期最长的路径
- 关键活动延期=项目延期

### 时差计算口诀
**「正向最晚取大值，反向最早取小值」**
- 正向计算：EF取紧前最大值
- 反向计算：LS取紧后最小值
- TF=LS-ES=LF-EF

### 进度压缩两技术口诀
**「赶工花钱加资源，快速跟进并行担风险」**
- 赶工Crashing：关键路径追加资源
- 快速跟进Fast Tracking：串行改并行

### 资源平衡vs平滑口诀
**「平衡改路径可能延期，平滑改活动不延不变径」**
- 平衡：可能延长工期
- 平滑：只调整非关键活动，不延工期

### 三点估算公式口诀
**「乐四悲六除，方差悲乐差六除」**
- 期望工期 = (O + 4M + P) / 6
- 标准差σ = (P - O) / 6
- 方差σ² = ((P - O) / 6)²

### 挣值三参数口诀
**「PV计划 EV挣值 AC实际」**
- PV：Planned Value 计划值
- EV：Earned Value 挣值
- AC：Actual Cost 实际成本

### 挣值四指标口诀
**「CV减 AC比较 EV减 PV」**
- CV = EV - AC（成本偏差）
- SV = EV - PV（进度偏差）
- 正向有利、负向不利

### 挣值两指数口诀
**「CPI挣除实，SPI挣除计」**
- CPI = EV / AC（成本绩效）
- SPI = EV / PV（进度绩效）
- 大于1有利

### EAC完工估算口诀
**「典型公式BAC除CPI，历史公式AC加ETC」**
- 典型EAC = BAC / CPI
- 历史EAC = AC + (BAC - EV)
- 预测偏差VAC = BAC - EAC

### 储备两分类口诀
**「应急已识管理未识」**
- 应急储备：已识别风险，PM可动用
- 管理储备：未识别工作，需变更程序
- 成本基准=预算+应急储备（不含管理储备）

### 等保三级五层面口诀
**「物网主应数」**
- 物理安全
- 网络安全
- 主机安全
- 应用安全
- 数据安全
- 三级测评每年一次
