## 今日核心概念
### 1. 项目质量管理（QC七大工具与质量保证/控制）
定义：在项目过程中为满足干系人质量期望而实施的全面管理活动，含质量规划、质量保证、质量控制三过程。
关键要点：
- 质量规划：识别质量标准、确定如何满足，输出质量管理计划与可交付物的质量度量指标
- 质量保证（QA）：过程导向、贯穿项目全过程、预防为主，目标是建立信心让过程正确
- 质量控制（QC）：产品导向、聚焦可交付物、检查为主，目标是发现并消除缺陷
- QA与QC区别：QA管过程、QC管产品；QA事前预防、QC事后检查；QA贯穿全程、QC集中节点
- QC七大工具：因果图（鱼骨图）、流程图、核对单、帕累托图、直方图、控制图、散点图
- 七大工具分类：分析问题（因果图/流程图/散点图）、过程监控（控制图）、数据展示（直方图）、优先级（帕累托）、防错（核对单）
- 质量成本：预防成本、鉴定成本、内部失败成本、外部失败成本，前两项投入越多后两项越低

### 2. 项目成本管理（挣值分析EVM全套指标）
定义：在批准的预算内完成项目所需的全部过程，含规划成本、估算预算、确定预算、控制成本四过程。
关键要点：
- 三大基本值：PV计划值（按计划应完成工作的预算）、EV挣值（实际完成工作的预算）、AC实际成本（实际花费）
- 进度偏差SV = EV − PV，SV>0提前、SV<0滞后、SV=0符合
- 成本偏差CV = EV − AC，CV>0节约、CV<0超支、CV=0符合
- 进度绩效指数SPI = EV/PV，>1提前、<1滞后
- 成本绩效指数CPI = EV/AC，>1节约、<1超支
- 完工估算EAC = BAC/CPI（当前绩效延续），ETC = EAC − AC
- 完工偏差VAC = BAC − EAC，TCPI = (BAC−EV)/(BAC−AC) 后续工作的成本绩效要求
- 典型计算：SPI=0.8进度滞后、CPI=0.889成本超支、EAC=BAC/CPI

### 3. 信息系统合同管理（条款构成+违约责任+争议解决）
定义：对采购合同从签订、履行、变更到关闭的全过程管理，是项目执行与法务风险防控的核心。
关键要点：
- 合同三要素：主体（具备相应民事权利能力）、标的（项目范围与交付物）、价款（金额与支付方式）
- 合同核心条款：定义与解释、范围与目标、工期进度、价款支付、验收标准、知识产权、保密、违约责任、争议解决
- 违约金：合同预定一方违约时支付对方的金额，可为固定金额或计算方式，违约金过分高于/低于实际损失可请求调整
- 损害赔偿：实际损失+可得利益损失，不得超过违约一方订立合同时预见到或应当预见到的损失
- 合同争议解决四步：协商→调解→仲裁→诉讼，仲裁一裁终局、诉讼两审终审
- 合同管理三过程：合同签订（评审、会签、签字盖章）→合同履行（变更、记录、监控）→合同收尾（验收、归档、关闭）
- 与项目收尾关系：合同收尾是项目收尾的输入，验收合格是合同关闭的前提

### 4. 项目收尾管理（合同收尾+行政收尾）
定义：项目正式结束所需的过程，含合同收尾与行政收尾两个子过程，目标是把项目产品/服务正式移交给客户并沉淀经验。
关键要点：
- 合同收尾：完成合同条款、解决未决索赔、办理最终付款、签订验收报告；输出合同关闭证明
- 行政收尾：产品/服务正式移交、文档归档、项目档案移交、经验教训总结、释放资源
- 行政收尾五件套：项目档案、经验教训登记册、最终产品/服务移交报告、资源释放报告、给干系人的最终通知
- 经验教训三原则：客观记录、结构化模板、可复用推广；避免甩锅、避免夸大、避免敷衍
- 组织过程资产更新（OPA）：流程资产（模板、流程）+数据资产（度量数据、绩效数据）+知识资产（最佳实践）
- 移交五步：测试验收→试运行→终验签字→正式运行支持→质保期管理
- 项目收尾未做的影响：经验流失、资源浪费、合同纠纷、影响后续项目复用

### 5. 知识产权与软件资产管理（著作权+专利权+商业秘密）
定义：信息系统建设中涉及的知识产权归属、保护与管理，以及软件资产全生命周期管理的体系。
关键要点：
- 软件著作权自完成之日起自动产生，无需申请；登记证书是诉讼举证的有力证据
- 专利权三性：新颖性、创造性、实用性；发明专利20年、实用新型10年、外观设计15年
- 商标权三要件：显著性、不冲突、合法性；注册原则，先注先得
- 商业秘密三要件：秘密性、价值性、保密性；员工保密协议与竞业禁止是关键
- 软件资产全生命周期：采购→入库→部署→使用→维护→退役→销毁，各阶段均有相应台账与责任人
- 软件资产台账：软件名称、版本、授权数、授权类型、使用人、部署位置、到期日、采购金额
- 软件正版化：所有在用软件须为正版授权，杜绝盗版，避免法律风险与安全风险
- 知识产权归属：合同明确约定是项目知识产权管理的核心，避免事后纠纷

## 案例分析题
**题目**：某市"市场监管一体化平台"建设项目，预算2000万元，工期18个月，由某IT公司中标承建。建设过程中出现以下问题：
- 问题一：项目已进展12个月，但测试中发现严重缺陷12个、中等缺陷56个，用户代表投诉"系统不稳定"。
- 问题二：项目预算已花费1300万元（占比65%），但通过挣值分析发现PV=1200万、EV=1000万、AC=1300万。
- 问题三：合同中未明确知识产权归属，承建方将平台源代码版权登记在自己名下，业主方要求修改。
- 问题四：合同未约定违约金具体计算方式，项目延期3个月，业主方索赔困难。
- 问题五：项目即将完工，但承建方准备撤离，技术文档、操作手册、源代码未完整交付，业主方无法独立运维。

问题：
1. 针对问题一，请说明QA与QC的区别，并给出QC七大工具中适合本场景的三种工具及适用场景。
2. 针对问题二，请计算SV、CV、SPI、CPI，并判断项目进度与成本绩效，给出EAC完工估算值。
3. 针对问题三，请说明知识产权的归属原则，并给出合同中应如何约定源代码归属。
4. 针对问题四，请说明违约金与损害赔偿的区别，并给出合同中违约金条款的设计要点。
5. 针对问题五，请说明项目收尾管理的两个子过程，并列出行政收尾的五件套。

**参考答案**：
1. QA与QC区别及工具：
   - QA（质量保证）：过程导向、贯穿全程、预防为主、建立过程信心
   - QC（质量控制）：产品导向、节点检查、发现缺陷、聚焦可交付物
   - 三种工具及场景：①帕累托图（按缺陷类型统计，找到占比80%的关键缺陷类型优先修复）②因果图/鱼骨图（分析缺陷根因，从人机料法环测六个维度展开）③控制图（监控测试过程稳定性，识别异常波动）
   - 整改：建立质量管理计划，明确每个里程碑的QA检查点与QC节点；缺陷修复后做回归测试；记录缺陷数据用于质量度量

2. 挣值计算与判断：
   - 已知PV=1200万、EV=1000万、AC=1300万、BAC=2000万
   - SV = EV − PV = 1000 − 1200 = −200万，SV<0，进度滞后
   - CV = EV − AC = 1000 − 1300 = −300万，CV<0，成本超支
   - SPI = EV/PV = 1000/1200 ≈ 0.833，SPI<1，进度滞后（仅完成计划的83.3%）
   - CPI = EV/AC = 1000/1300 ≈ 0.769，CPI<1，成本超支（每花1元仅创造0.77元价值）
   - EAC = BAC/CPI = 2000/0.769 ≈ 2600万，预计最终总成本将达2600万，超支600万
   - 整改：分析成本超支原因（范围蔓延/资源浪费/进度延误间接成本）；分析进度滞后原因；申请变更或调整基准；强化成本与进度控制

3. 知识产权归属：
   - 软件著作权自完成之日起自动产生，原则上归属开发者（承建方）
   - 业主方要取得著作权，必须在合同中明确约定"著作权归属甲方"或"著作权转让给甲方"
   - 合同应明确：①源代码、文档、设计图等全部成果的著作权归属甲方 ②承建方仅享有署名权 ③未经甲方书面同意，承建方不得擅自向第三方提供或申请登记 ④源代码必须随项目移交
   - 整改：本项目合同未约定，应通过补充协议约定源代码归业主方，并撤销承建方的不当登记

4. 违约金与损害赔偿：
   - 违约金：合同预先约定，违约方按约定金额或计算方式支付给对方，可高于实际损失（可请求调整）
   - 损害赔偿：按实际损失+可得利益计算，遵循可预见性原则
   - 违约金条款设计要点：①明确计算方式（如"每延期1天按合同总价0.5‰支付违约金，最高不超过合同总价10%"）②明确支付时点（逾期支付需支付利息）③明确与损害赔偿的关系（约定优先适用违约金）④明确争议解决方式⑤附条件可调整机制
   - 整改：补充签订违约金条款，明确延期3个月违约金的具体金额与计算方式

5. 项目收尾管理：
   - 两个子过程：合同收尾（完成合同条款、解决索赔、最终付款、签订验收报告）、行政收尾（产品移交、文档归档、经验教训、资源释放）
   - 行政收尾五件套：①项目档案（含全部技术与管理文档）②经验教训登记册③最终产品/服务移交报告④资源释放报告（人员、设备、设施释放）⑤给干系人的最终通知（项目正式结束）
   - 整改：要求承建方完整交付技术文档、操作手册、源代码；组织项目验收；召开项目总结会；将经验教训录入组织过程资产库；正式关闭项目

**踩分要点**：
- 第1题：QA过程导向、QC产品导向必答；QC七大工具中帕累托/鱼骨图/控制图/直方图任答三种且要配适用场景
- 第2题：SV、CV、SPI、CPI四个公式必算对；EAC=BAC/CPI公式必答；判断结论"进度滞后+成本超支"必答出
- 第3题：著作权自动归属原则必答；合同约定"源代码归甲方"必答；撤销不当登记必答
- 第4题：违约金"预先约定"、损害赔偿"实际损失"必答；违约金条款要点要答"计算方式+支付时点+与损害赔偿关系"
- 第5题：合同收尾+行政收尾两个子过程必答；行政收尾五件套"档案+经验+移交报告+资源释放+最终通知"必答全

## 记忆口诀
### QA与QC区别口诀
**「QA管过程贯穿防，QC管产品节点查」**
- QA：过程导向、预防为主、贯穿全程
- QC：产品导向、检查为主、集中节点
- QA建过程信心，QC找产品缺陷

### QC七大工具口诀
**「因果流程核对单，帕累直方控制散」**
- 因果图（鱼骨图）：人机料法环测找根因
- 流程图：分析过程步骤
- 核对单：防错清单
- 帕累托图：二八原则找关键
- 直方图：数据分布展示
- 控制图：过程稳定性监控
- 散点图：两变量相关性

### 挣值分析口诀
**「PV计划EV挣AC实，SV减CV减SPI除」**
- PV（计划值）：按计划应完成工作的预算
- EV（挣值）：实际完成工作的预算
- AC（实际成本）：实际花费
- SV = EV − PV（>0提前<0滞后）
- CV = EV − AC（>0节约<0超支）
- SPI = EV/PV（>1提前<1滞后）
- CPI = EV/AC（>1节约<1超支）

### EAC完工估算口诀
**「BAC除CPI得EAC，ETC就是剩多少」**
- EAC = BAC/CPI（当前绩效延续到完工）
- ETC = EAC − AC（还需多少）
- VAC = BAC − EAC（完工偏差）
- TCPI = 剩余工作必须的成本绩效

### 合同争议解决口诀
**「协调仲诉」**
- 协商（友好解决）
- 调解（第三方介入）
- 仲裁（一裁终局）
- 诉讼（两审终审）
- 合同务必约定争议解决方式

### 项目收尾口诀
**「合同收尾加行政收尾」**
- 合同收尾：解决索赔+最终付款+验收签字
- 行政收尾：产品移交+文档归档+经验沉淀
- 五件套：档案+经验+移交报告+资源释放+最终通知

### 知识产权归属口诀
**「著自完专20+商三要件」**
- 软件著作权自完成之日起自动产生
- 专利发明20年、实用新型10年、外观15年
- 商标权三要件：显著性、不冲突、合法性
- 合同明确约定是归属核心

### 质量成本口诀
**「预鉴内外，越投越省」**
- 预防成本（培训、流程优化）
- 鉴定成本（测试、检查）
- 内部失败成本（返工、报废）
- 外部失败成本（保修、赔偿）
- 前两项投入越多后两项越低
