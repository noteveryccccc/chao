## 今日核心概念
### 1. IT治理成熟度评估模型
定义：以标准化问卷+证据审计方式，量化组织在治理目标（EDM）与管理体系（APO/BAI/DSS/MEA）上的达成度，形成0-5级成熟度等级与差距图谱，为治理改进提供基线。
关键要点：
1. COBIT 2019能力域六级：无(0)/不完整(1)/已实施(2)/已管理(3)/已定义(4)/优化中(5)，强调流程属性PA 1.1-5.2共11项全过线
2. 评估三维度：流程能力+组织结构成熟度+信息流成熟度，单一维度高不能代表整体高
3. 差距分析后必须形成Roadmap，按高-中-低优先级分批改进，6-12月一周期
4. 与ISO 38500治理成熟度、ITIL成熟度评估形成互补，COBIT偏治理，ITIL偏运营
5. 评估输出三件套：成熟度得分雷达图+差距清单+改进建议库，需董事会背书

### 2. 信息化项目群治理与项目组合管理（PPM）
定义：在组织战略目标驱动下，对多个相关联信息化项目进行集中识别、优先级排序、组合选择、资源平衡与价值跟踪，确保项目集整体投资收益最大化。
关键要点：
1. 战略-组合-项目集-项目四级漏斗：战略主题→组合→项目集→项目，自上而下分解，自下而上汇总价值
2. 组合选择四象限：战略必要/财务必要/战略可选/财务可选，砍掉两项都不沾的"花瓶项目"
3. 项目集治理关键：共享资源池、通用风险、共性干系人、单项目无法获得的协同收益
4. 价值跟踪三指标：NPV净现值、ROI投资回报率、战略对齐度，每年至少复盘一次
5. 项目集经理与项目经理权责清晰：项目集管"做什么、为什么、是否继续"，项目经理管"怎么做、按时按质"

### 3. IT服务质量评价与持续服务改进（CSI）
定义：以ITIL七步改进法为骨架，建立服务质量度量-分析-改进闭环，使服务质量从"被动响应"走向"主动预防"，从"达标"走向"卓越"。
关键要点：
1. CSI七步法：定义愿景→评估现状→确定目标→收集数据→处理数据→分析信息→实施改进，PDCA循环嵌套
2. 服务质量四维度模型：功能性（能否做）+可靠性（稳定吗）+可用性（易用吗）+安全性（可控吗），对应ISO/IEC 25010
3. 度量四类型：技术度量（CPU/响应时间）+流程度量（事件解决率）+服务度量（CSAT/NPS）+业务度量（业务影响度）
4. 改进项目化：每个改进项必须立项SMART目标+责任人+里程碑，避免"持续改进"沦为口号
5. 与六西格玛、精益、敏捷融合：DMAIC定义-测量-分析-改进-控制，对应ITIL但更量化

### 4. 数字化转型成熟度模型与转型路径
定义：以业务-组织-技术-数据四维度对组织数字化水平进行分级诊断，制定从"初始级"到"优化级"乃至"生态级"的演进路线，是数字化转型咨询与评标的标尺。
关键要点：
1. 数字化转型五级模型：初始级（电子化）-单元级（信息化）-流程级（数字化）-战略级（智能化）-生态级（平台化），逐级不可跳跃
2. 转型四支柱：战略与组织（顶层设计）+业务流程（端到端重塑）+技术平台（云数智链）+数据资产（要素化），缺一不可
3. 路径选择：激进式（业务推倒重来，3-5年）vs渐进式（先试点后推广，5-8年），国企/政府首选渐进
4. 关键成功因素：一把手工程+业务深度参与+数据治理先行+小步快跑验证+生态共建共治
5. 与传统信息化区别：数字化以数据驱动决策+以客户为中心+以生态为边界，不再是技术项目而是业务变革

### 5. IT服务外包合同治理与SLA违约处置
定义：通过合同条款设计、SLA量化指标、违约赔付机制、争议解决流程与定期评估，对外包服务商进行全生命周期治理，规避"一签了之、续签时扯皮"陷阱。
关键要点：
1. 合同治理三阶段：签约前（权责清晰+退出条款）+履约中（监控+考核+纠偏）+收尾时（资产移交+知识转移+对账）
2. SLA四级量化：响应时间（分钟级）+解决时间（小时级）+可用率（99.9%/99.99%/99.999%）+满意度（CSAT≥4.5）
3. 违约处置五手段：警告信→扣款→赔偿→接管→终止，按严重程度分级触发，避免小事闹大或大事化了
4. 退出机制必备：源代码/数据/密码/文档/物理资产移交清单+过渡期协助+不可抗力免责，避免"绑架"
5. 多供应商治理：避免单一供应商绑架，重要系统至少2家备选，定期开展供应商能力评估与对标

## 案例分析题
**题目**：阅读下列案例，回答问题。
M市卫健委承担"健康M市"全民健康信息平台升级改造项目，总投资8200万元，建设周期2年，包含市级全民健康数据中心、AI辅助诊断、互联网医院、医联体协同、家庭医生签约五大子系统。项目采用"咨询+总集+监理+建设"四方模式，由A公司总集成、B公司监理、C公司牵头咨询。项目实施一年后暴露出以下问题：
（1）项目集管理混乱，五大子系统由不同科室分头建设，缺乏统一架构标准，数据模型不互通，形成新的"数据烟囱"；
（2）SLA仅在总包合同中原则性约定，未分解到各子系统，甲方无法量化考核；
（3）总集A公司因利润压力将AI模块转包给D公司，但未在合同中明确二级分包条款，监理B公司未及时发现；
（4）市卫健委信息中心仅3人负责项目管理，无项目集管理办公室（PMO），各科室各自为政；
（5）项目原计划2025年底上线，目前进度仅完成45%，卫健委主任被市政府约谈，要求"年底必须上线"；
（6）审计署后续审计发现项目存在重复建设、绩效目标不清、可持续运营能力不足三大问题。
问题：
1. 请指出本项目在治理层面的主要问题（至少5项）。
2. 针对年底必须上线的硬性要求，项目集经理应如何重新制定后续推进计划？
3. 请设计本项目五大子系统的SLA分级体系（含可用率、响应时间、解决时间）。
4. 针对分包合规性问题，应如何整改并完善合同治理？
5. 项目终验后应开展哪些后评价工作？至少列出5项。

**参考答案**：
1. 治理层面主要问题：①缺乏项目集治理委员会与PMO，五大子系统无人统一协调；②未制定统一架构标准与数据治理规范，造成数据烟囱；③SLA未量化分解到子系统，无法考核；④总包合同未约定分包条款，二级转包存在合规风险；⑤监理未履职尽责，未及时发现转包问题；⑥甲方信息中心能力不足（仅3人），缺乏专业项目管理；⑦绩效目标不清，验收标准模糊；⑧可持续运营与商业模式缺位，建得起用不起。
2. 重新制定推进计划：①立即启动变更控制，评估各子系统实际剩余工作量与关键路径；②按"核心先上线、外围后完善"原则做MVP分层，明确必上线、可延后、可裁剪三类；③成立PMO+项目集治理委员会，每周调度+月度评估；④引入外部专家团队补强甲方能力；⑤与市政府沟通设定分阶段里程碑（如12月数据中心+家庭医生上线、AI模块延至次年6月），避免一次性全上线风险；⑥重新基线化进度、范围、成本三要素并报变更控制委员会CCB审批。
3. SLA分级体系：①核心-全民健康数据中心：可用率99.99%、响应时间≤15分、解决时间≤4小时；②重要-AI辅助诊断+互联网医院：可用率99.95%、响应≤30分、解决≤8小时；③一般-医联体协同+家庭医生签约：可用率99.9%、响应≤1小时、解决≤24小时；④配套：月度可用率报告+季度SLA考核+年度第三方评估+违约扣款比例（每低0.01%扣合同额2%）。
4. 分包合规整改：①立即暂停D公司AI模块工作，开展合规审查；②按合同法/招标投标法/政府采购法评估违约责任，必要时约谈警告或索赔；③完善总集合同分包条款：分包比例上限（不超过30%）、核心模块禁止分包、分包审批流程、二级分包商资质要求；④建立分包商黑名单与年度复评机制；⑤追究B监理公司失职责任，扣减监理费并要求更换总监；⑥建立合同变更控制委员会CCB，所有合同变更必须留痕。
5. 项目后评价工作：①目标达成度评价（对照可研批复的KPIs）；②经济效益评价（NPV/ROI/IRR）；③社会效益评价（群众就医获得感、医护满意度）；④技术性能评价（架构先进性、技术成熟度、自主可控率）；⑤可持续运营能力评价（运维费用来源、商业模式、人才储备）；⑥过程合规性评价（招标采购、合同执行、变更控制、监理履职）；⑦经验教训总结（最佳实践库+教训教训库）；⑧第三方独立审计+绩效评价报告向社会公开。

**踩分要点**：
1. 第1问：必答"无PMO+无统一架构+SLA未量化+分包不合规+监理失职+甲方能力不足"六大点，答出5项即满分
2. 第2问：必须体现MVP分层思想+CCB变更控制+分阶段里程碑+与市政府沟通机制四个要点
3. 第3问：SLA分级按核心/重要/一般三级，量化指标包含可用率、响应时间、解决时间，并配扣款机制
4. 第4问：整改动作必含暂停+审查+完善合同+追究监理+建机制五步
5. 第5问：覆盖目标+经济+社会+技术+运营+合规+经验教训+审计八个维度，答出5项即满分

## 记忆口诀
1. **成熟度五级口诀**：无完实管定优（无→不完整→已实施→已管理→已定义→优化中），COBIT六级逐级跃；
2. **PPM四漏斗**：战略→组合→项目集→项目，自上分解自下汇总，对应沙盘推演；
3. **CSI七步法**：愿评目收处分改（愿景→评估→目标→收集→处理→分析→改进），PDCA套PDCA；
4. **服务质四维**：功可安靠安可安保（功能性+可靠性+可用性+安全性），对应ISO 25010；
5. **转型五级**：初电单流战智生（初始-电子化→单元-信息化→流程-数字化→战略-智能化→生态-平台化），逐级不可越；
6. **SLA四级量**：响分解决满意度（响应时间→解决时间→可用率→满意度），由秒级到季度；
7. **分包三道闸**：比例限+核心禁+审批严，避免二级三级转包成"老鼠仓"；
8. **后评价八维**：目经社技运合教审（目标+经济+社会+技术+运营+合规+教训+审计），验收后必做；
9. **治理六字诀**：定标治评改决（定目标→立标准→抓治理→勤评估→快改进→严决策），循环嵌套；
10. **四防口诀**：防绑架+防烟囱+防失职+防花瓶，多供应商+统一架构+监理独立+绩效对齐。
