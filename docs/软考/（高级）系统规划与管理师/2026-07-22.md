## 今日核心概念
### 1. 信息技术服务预算管理
定义：依据组织战略、业务需求和服务目标，对信息技术服务所需资金进行预测、编制、审批、执行、监控与调整的全过程管理活动。
关键要点：
1. 预算编制应以服务目录、历史成本、业务增长和能力需求为依据，避免仅按上年金额简单增减。
2. 预算通常分为资本性支出和运营性支出，前者用于形成长期资产，后者用于维持日常服务。
3. 预算执行要建立月度监控、偏差预警和滚动预测机制，发现偏差后及时分析数量、价格、范围和效率原因。
4. 预算调整必须履行申请、论证、审批和留痕程序，不得以紧急需求为由绕过控制。
5. 考试答题应强调预算与战略、服务级别及绩效目标联动，防止只控费用、不管价值。

### 2. 信息技术服务成本核算
定义：按照统一口径归集、分配和计算信息技术服务所消耗资源成本，为定价、预算、绩效评价和投资决策提供依据。
关键要点：
1. 成本分为直接成本与间接成本，直接成本可直接归属于某项服务，间接成本需按合理动因分摊。
2. 常见成本对象包括业务系统、服务目录项、部门、项目和用户群体。
3. 分摊动因可选用户数、工时、设备数量、存储容量、调用次数和资源使用量，必须保持一致性与可追溯性。
4. 全生命周期成本不仅包括采购建设费用，还包括运维、升级、培训、迁移、停机和退出处置成本。
5. 成本核算的目标不是机械压缩费用，而是识别高成本低价值环节，支撑资源优化。

### 3. 信息技术服务计费与内部结算
定义：根据服务消耗量、成本和约定规则，将信息技术服务费用分配或收取到相应业务部门，以促进成本透明和责任落实。
关键要点：
1. 不计费模式适合成本统一承担但透明度较低；分摊模式按规则分配成本；计费模式按实际消费形成内部账单。
2. 计费模型可采用固定包干、按量计费、阶梯计价和基础费用加用量费用等方式。
3. 内部结算应设置价格目录、计量规则、账单核对、争议处理和定期调价机制。
4. 计费指标必须可测量、可审计，避免采用无法验证的主观数据。
5. 推行计费要循序渐进，通常先实现成本可见，再开展成本分摊，最后实施精细化计费。

### 4. 信息技术服务价值管理
定义：从业务结果、风险降低、用户体验和资源效率等角度，持续评估并提升信息技术服务贡献的管理活动。
关键要点：
1. 服务价值由效用和保证共同构成，效用解决“是否有用”，保证解决“是否稳定可用”。
2. 价值评价不能只看成本，应综合业务收益、社会效益、合规保障、风险降低和用户满意度。
3. 对政府信息化项目，应重点评价公共服务改善、行政效能提升、数据共享和群众获得感。
4. 建立价值指标时要明确基线值、目标值、数据来源、统计周期和责任人。
5. 对长期低使用率、低贡献且高成本的服务，应采取整合、降级、替换或退出措施。

### 5. 信息技术资产全生命周期管理
定义：对硬件、软件、许可证、云资源和数字化设备从规划采购、登记配置、使用维护到报废处置进行全过程控制。
关键要点：
1. 资产管理关注财务价值、所有权和合规性，配置管理关注服务关系、状态及对业务的影响，两者既有区别又需联动。
2. 资产入库应建立唯一标识，记录采购合同、责任部门、使用人、位置、许可证和保修期限。
3. 软件许可证管理要防范超范围使用、闲置浪费和授权过期三类风险。
4. 云资源应纳入资产视角管理，通过标签、预算、闲置检测和自动回收治理资源浪费。
5. 报废处置必须完成审批、数据清除、介质销毁、资产核销和处置留痕，防止数据泄露与资产流失。

## 案例分析题
**题目**：某市大数据管理部门建设统一政务云，为全市四十余家单位提供计算、存储、网络、安全和运维服务。平台运行两年后发现：各单位申报资源时普遍留有较大余量，整体资源平均利用率不足百分之三十五；运维预算仍按上一年度金额统一增长百分之十编制，未与实际服务量挂钩；财务部门只能掌握设备采购和外包合同总额，无法计算单个系统或单项服务的成本；云资源由大数据管理部门统一承担费用，各使用单位看不到资源账单，长期存在大量闲置主机；软件许可证分散采购，部分重复购买，另有部分已经过期仍在使用；下线系统的服务器未及时回收，存储介质也没有规范的数据清除记录。审计部门要求该市在不降低关键政务服务质量的前提下，完善财务、价值与资产管理体系。

**参考答案**：
1. 主要问题：预算编制缺乏服务量和业务需求依据；未开展服务成本核算，成本对象与分摊规则不清；未建立内部结算或资源账单机制，使用单位缺少成本责任；资源申请和回收控制薄弱，形成大量闲置；许可证分散管理，存在重复采购与合规风险；下线资产处置不规范，存在资产流失和数据泄露风险；缺少服务价值评价，无法识别高成本低价值服务。
2. 预算管理改进：以服务目录、历史用量、业务增长和服务级别为基础编制预算；区分资本性支出和运营性支出；建立月度预算执行分析、偏差预警和滚动预测；预算调整统一纳入审批与变更控制；将预算执行结果与服务绩效评价联动。
3. 成本核算方案：以业务系统和服务目录项为成本对象；直接归集专用设备、专属软件和专职人员成本；将机房、网络、安全、公共运维等间接成本，按照虚拟处理器使用量、存储容量、网络流量、工时或用户数进行分摊；计算各服务全生命周期成本，形成成本台账和单位服务成本。
4. 内部结算方案：第一阶段向各单位提供资源使用量和模拟账单，实现成本可见；第二阶段按资源配额和实际用量进行成本分摊；第三阶段对超配额资源实施按量或阶梯计费。建立价格目录、月度账单、核对申诉、调价和预算联动机制。
5. 资源与资产优化：开展闲置资源盘点，设置低利用率阈值和回收期限；对长期闲置主机执行通知、确认、备份和回收；建立软件许可证统一采购、统一登记、使用监测和到期预警；资产与配置项建立关联；下线资产严格执行审批、数据清除、介质销毁、核销和审计留痕。
6. 价值保障措施：关键民生系统应设置最低资源保障和弹性扩容机制，不得简单削减；建立成本、可用率、资源利用率、用户满意度、业务办理效率和风险降低等指标；对高成本低价值服务实施整合、降级或退出，对高价值关键服务优先保障。

**踩分要点**：
1. 指出预算、成本、计费、价值、资产五类管理缺陷，且能对应案例具体表现。
2. 成本核算必须写出成本对象、直接成本、间接成本和分摊动因。
3. 内部结算应体现“先可见、再分摊、后计费”的渐进路径。
4. 资产整改必须包含许可证管理、闲置资源回收和报废数据清除。
5. 强调降本不能降低关键服务质量，应建立服务分级保障和价值评价指标。
6. 答案中出现预算偏差分析、滚动预测、全生命周期成本和审计留痕，可获得分析深度分。

## 记忆口诀
预算五步：预测、编制、审批、监控、调整。
成本四问：算什么、归哪里、怎么分、值不值。
结算三阶：先可见、再分摊、后计费。
价值双轮：效用管有用，保证管可靠。
资产五环：采、登、用、维、退；退役四清：审批清、数据清、账目清、责任清。
云资源治理口诀：统一标签、按量核算、闲置预警、到期回收、关键保障。
财务价值总口诀：预算有依据，成本能追溯，消费看得见，价值可衡量，资产管到底。
