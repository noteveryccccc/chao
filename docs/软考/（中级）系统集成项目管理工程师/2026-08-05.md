## 今日核心概念
### 1. 项目成本管理
定义：在批准的预算内完成项目所需的全部过程，包括成本估算、预算编制、成本控制三大过程组。
关键要点：
- 估算成本：自下而上估算、参数模型估算、三点估算、类比估算、储备分析
- 预算编制：成本基准、管理储备、应急储备、合同成本、融资成本
- 成本控制：挣值管理(EVM)、PV/EV/AC/CPI/SPI、CV/SV、ETC/EAC、TCPI、完工预测
- 成本类型：直接成本、间接成本、固定成本、可变成本、机会成本、沉没成本
- 储备分析：应急储备(已知未知)由项目经理支配，管理储备(未知未知)由高层控制

### 2. 挣值管理(EVM)
定义：通过整合范围、进度、成本三个维度，用统一指标度量项目绩效的管理方法。
关键要点：
- PV(计划值)：某时点计划完成工作的预算成本
- EV(挣值)：某时点实际完成工作的预算成本
- AC(实际成本)：某时点实际完成工作的实际成本
- CPI=EV/AC(成本绩效指数，>1节约/<1超支)
- SPI=EV/PV(进度绩效指数，>1提前/<1滞后)
- CV=EV-AC(成本偏差，正值节约/负值超支)
- SV=EV-PV(进度偏差，正值提前/负值滞后)
- EAC=BAC/CPI完工估算，ETC=BAC-EV剩余工作估算

### 3. 成本类型与COQ
定义：成本类型区分投入要素，COQ(质量成本)区分合规与不合规两类成本。
关键要点：
- 成本类型：直接成本(可直接归属)、间接成本(分摊)、固定成本(不随产量变化)、可变成本(随产量变化)
- COQ一致性成本(预防+ Appraisal)：预防成本、培训、流程改进、设备校准
- COQ不一致性成本(内部+外部失败)：返工、废品、保修、声誉损失
- 学习曲线理论：累计产量每翻倍，单位成本按固定比例下降
- 边际成本与边际收益：项目决策依据
- 投资回收期与NPV：项目经济性评价

### 4. 项目采购管理
定义：从项目外部获取项目所需产品、服务或成果的过程，包括采购规划、合同管理、合同收尾。
关键要点：
- 采购规划：自制或外购分析、市场调研、专家判断
- 合同类型：FFP固定总价(范围清晰)、FP/T&M时间材料(范围不明)、CPFF成本加固定费用、CPIF成本加激励费用、CPPC成本加奖励
- 采购工作说明书(SOW)：详细描述采购项，便于供应商响应
- 招标文件：信息邀请书RFI、报价邀请书RFQ、建议邀请书RFP
- 供方选择：加权打分、筛选、谈判、独立估算、卖方评级
- 合同管理：变更控制、绩效报告、付款、争议处理
- 合同收尾：经验教训、文档归档、正式验收

### 5. 项目资源管理与团队建设
定义：有效率且有效用地利用人力、物力、财力资源，确保项目团队高效运作。
关键要点：
- 团队组建：预分派、谈判、虚拟团队、采购、招聘
- 团队建设五阶段(塔克曼)：形成期、震荡期、规范期、成熟期、结束期
- 领导风格：命令型、教练型、支持型、授权型，匹配团队成熟度
- 激励理论：马斯洛需求层次、赫茨伯格双因素、麦格雷戈X/Y理论、期望理论
- 冲突管理：合作/妥协/缓和/回避/强迫五种策略
- 资源分配：资源平衡(调整进度)、资源平滑(不改变关键路径)
- RAM责任分配矩阵：RACI责任分配(Responsible/Accountable/Consulted/Informed)

## 案例分析题
**题目**：
某政府单位启动"智慧政务一网通办"系统建设项目，项目总预算1200万元，工期18个月，采用EVM挣值管理。项目进行到第9个月时进行绩效测量，相关数据如下：
- 计划预算BAC=1200万元
- 第9个月计划完成工作量PV=600万元
- 第9个月实际完成工作量EV=540万元
- 第9个月实际花费成本AC=720万元
- 已发现重大需求变更4项，额外增加成本约80万元
- 项目组因人员流动，关键岗位开发人员流失3人
- 合同类型：与主要集成商签订CPFF合同，与硬件供应商签订FFP合同

问题：
1. 计算当前CPI、SPI、CV、SV，并分析项目绩效。
2. 按当前绩效计算EAC、ETC、VAC，预测完工成本。
3. 针对需求变更和人员流失问题，应采取哪些措施？
4. 项目经理计划在剩余工作中采用赶工方式，是否合理？CPFF和FFP两种合同对成本控制的影响有何不同？

**参考答案**：
1. 绩效分析：
- CPI=EV/AC=540/720=0.75(<1，超支33%)
- SPI=EV/PV=540/600=0.9(<1，进度滞后10%)
- CV=EV-AC=540-720=-180万元(负值超支)
- SV=EV-PV=540-600=-60万元(负值滞后)
- 综合判断：项目处于"超支+滞后"双重不利状态，且成本超支比进度滞后更严重(CPI<SPI且差距明显)

2. 完工预测：
- EAC=BAC/CPI=1200/0.75=1600万元
- ETC=EAC-AC=1600-720=880万元
- VAC=BAC-EAC=1200-1600=-400万元(完工后将超支400万)
- TCPI=(BAC-EV)/(BAC-AC)=(1200-540)/(1200-720)=660/480=1.375
- 若按新BAC=1280万元(含80万变更)：EAC'=1280/0.75=1706.67万元

3. 应对措施：
- 需求变更：严格执行变更控制流程(CCB评审)、分析变更影响、做好范围基准更新、沟通管理、变更文档化
- 人员流失：知识管理、文档化交接、团队建设激励、关键岗位备份、薪酬激励改善
- 综合：风险再评估、储备分析复盘、加强质量管理减少返工、优化资源平衡

4. 赶工分析：
- 赶工(crashing)适用于关键路径上赶工成本低于延误损失的情况
- 需评估赶工的成本边际收益，对照SPI计算是否值得
- 本项目CPI=0.75已严重超支，赶工会进一步加剧成本压力，需慎重
- CPFF合同：买方承担成本超支风险，超支部分仍需支付固定费用
- FFP合同：卖方承担成本风险，超支风险由卖方承担，但可能影响交付质量
- 建议：先做挣值复盘和范围梳理，再决定赶工或重新基线化(BAC=1280)

**踩分要点**：
1. EVM四大指标CPI/SPI/CV/SV必须计算正确，结果必须配合绩效判断
2. EAC预测需说明假设条件(BAC/CPI)，不能简单套公式
3. 应对措施要扣"变更控制六步"和"团队建设五阶段"，不能空话
4. 赶工分析需说明成本-收益对比，两种合同对比要说清风险归属

## 记忆口诀
- 成本三过程：估算预编制，控制成本管理
- EVM三值：PV计划值、EV挣值、AC实际值
- EVM四指数：CPI成本绩效、SPI进度绩效、CV成本偏差、SV进度偏差
- EVM完工预测：EAC= BAC/CPI、ETC=EAC-AC、VAC=BAC-EAC
- TCPI完工尚需绩效：(BAC-EV)/(BAC-AC)
- 储备二分法：应急储备项目经理管(已知未知)、管理储备高层控(未知未知)
- COQ两分类：一致性(预防+鉴定)、不一致性(内部失败+外部失败)
- 合同五种类型：FFP总价/FP时间材料/CPFF成本加固定费/CPIF成本加激励/CPPC成本加奖
- 团队建设五阶段：形成震荡规范成熟结束(塔克曼)
- 冲突五策略：合作/妥协/缓和/回避/强迫(合作最优、强迫最差)
- 激励四理论：马斯洛需求/赫茨伯格双因素/X-Y理论/期望理论
- RAM责任矩阵：R执行/A问责/C咨询/I知情
- 资源平衡vs平滑：平衡改变关键路径、平滑不改变关键路径
- 学习曲线：累计产量翻倍、单位成本按固定比例下降
- 成本失控预警：CPI连续低于1、SPI连续低于1、TCPI>1.1
