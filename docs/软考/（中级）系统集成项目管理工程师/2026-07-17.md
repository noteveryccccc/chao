## 今日核心概念

### 1. 项目采购管理过程与采购合同
定义：项目采购管理是从外部获取项目所需产品、服务或成果的全过程管理活动，包括采购规划、招标准备、供方选择、采购合同管理和采购合同收尾等过程，目的是在满足质量、进度和成本要求的前提下获得合格的外部交付。

关键要点：
- 采购管理过程包括规划采购管理、实施采购、控制采购和结束采购四个环节。
- 采购合同是买卖双方就交付物、质量标准、进度节点、付款方式、违约责任和验收方式达成的具有法律约束力的协议。
- 常见合同类型包括总价合同、成本补偿合同和工料合同，应根据工作范围清晰程度、风险承担和成本控制要求选择。
- 采购规划阶段应确定是否外购、采购方式、评标方法、合同类型和支付方式。
- 实施采购阶段通过招标、询价、竞争性谈判或单一来源等方式选择供方，并完成合同评审与签订。

### 2. 工作说明书与采购管理计划
定义：工作说明书是详细描述拟采购货物、工程或服务的范围、技术要求、性能指标、交付方式和验收条件的文件。采购管理计划是明确采购活动如何开展、谁负责、何时开展以及如何管理的项目管理计划组成部分。

关键要点：
- 工作说明书应足够详细，使潜在供方能够判断是否具备履约能力，并据此准备应答方案。
- 采购管理计划应包括采购目标、采购方式、合同类型、评标办法、采购时间表、风险预案和责任分工。
- 工作说明书与范围基准密切相关，任何对工作说明书的修改都应履行整体变更控制流程。
- 采购管理计划应与项目章程、项目管理计划和需求文件保持一致，避免出现合同条款与项目计划冲突的情况。
- 对复杂集成项目，工作说明书应分别明确软硬件产品、系统集成、培训服务、运维服务和售后支持的不同要求。

### 3. 供方选择与评标方法
定义：供方选择是依据招标文件、采购管理计划和评标标准对潜在供方的资质、方案、价格、交付能力和履约风险进行综合评估并最终确定中标方的过程。评标方法包括最低评标价法、综合评估法和性价比法。

关键要点：
- 最低评标价法适用于标准化产品、规格清晰和市场价格透明的采购，要求供应商响应文件必须实质性响应招标文件。
- 综合评估法根据价格、技术方案、实施方案、资质业绩和售后服务等评分项进行加权打分，按总分排名推荐中标候选人。
- 性价比法是综合评估法的变种，侧重性能价格比，适用于定制化软件、系统集成和服务类采购。
- 评标过程应组建评标委员会，遵循公平、公正、公开原则，并形成书面评标记录和推荐意见。
- 公开招标应发布招标公告和招标文件，邀请不特定的法人或其他组织投标；邀请招标应向三个以上特定供方发出投标邀请。

### 4. 采购合同管理与控制采购
定义：采购合同管理是监督供方履约、处理合同变更、控制采购成本并对交付物进行检查验收的过程。控制采购是依据合同条款和采购管理计划跟踪供方绩效、识别风险并实施纠正措施的过程。

关键要点：
- 控制采购过程应持续跟踪供方的进度、质量、成本和合同条款执行情况，并将结果同步到项目整体绩效。
- 供方交付物应按合同约定的验收标准进行检查，包括功能测试、性能测试、文档审核和试运行验证。
- 合同变更应提交正式书面变更申请，经双方授权代表签字并报变更控制委员会或对应管理层审批。
- 出现违约、争议或不可抗力时，应依据合同争议解决条款处理，必要时通过调解、仲裁或诉讼解决。
- 合同支付应与里程碑验收结果挂钩，避免一次性大额支付带来的履约风险。

### 5. 采购合同收尾与经验教训
定义：采购合同收尾是完成合同条款、办理结算手续、移交交付物、关闭合同档案并记录经验教训的过程，标志着采购关系的正式结束。

关键要点：
- 采购合同收尾应完成全部交付物的最终验收、合同款项结算、履约评价和文件归档。
- 项目经理应组织采购总结，复盘供方履约能力、合同执行过程、风险处理结果和成本控制效果。
- 经验教训应记录到组织过程资产，供后续采购活动参考，包括供方优缺点、合同条款陷阱和应对方法。
- 合同未关闭前不得随意终止采购收尾，所有遗留问题应形成清单并指定责任人限期处理。
- 采购档案应按组织档案管理规定保存，保存期限应满足法律法规、采购合同和审计要求。

## 案例分析题
**题目**：某市“智慧政务一体化平台”项目预算四千五百万元，工期十八个月。项目包含基础平台搭建、业务系统集成、数据治理和运维服务四部分内容。项目经理组织采购时出现以下情况：

（1）招标文件中的工作说明书仅写了“提供一体化平台建设服务”，没有列出具体模块清单、技术指标、接口要求、验收标准和运维响应时间。多家潜在供方反馈招标文件不够清晰。

（2）评标委员会采用最低评标价法选择供应商，最终中标公司报价明显偏低，但在实施方案中提出大量范围外接口、数据迁移和定制开发要求。中标后要求追加合同金额。

（3）合同签订后，供应商未能按里程碑交付核心模块开发成果，项目经理三次通过电话催促后没有形成书面记录，也没有提交正式变更或索赔申请。

（4）项目进入验收阶段后，供应商交付的技术文档不全、培训未按计划开展，部分功能未通过验收测试，但项目经理为了赶工期直接签署了验收报告。

请回答：

一、指出本项目采购管理与合同管理中存在的主要问题。

二、针对工作说明书、评标方法、合同执行和验收环节分别提出改进措施。

三、说明采购合同收尾阶段应完成的主要工作。

**参考答案**：

一、主要问题：

1. 工作说明书不完整。招标文件未明确模块清单、技术指标、接口要求、验收标准和运维响应时间，潜在供方无法准确评估工作范围和成本，容易在签约后产生大量澄清和争议。

2. 评标方法选择不当。智慧政务一体化平台属于复杂系统集成项目，技术方案、实施方案、资质业绩和运维能力对项目成功影响很大，采用最低评标价法无法反映供方综合实力，导致报价不合理的中标人进入项目。

3. 合同执行过程缺乏书面记录和控制。供应商里程碑延误后，项目经理仅通过电话催促，未形成书面催告、未评估违约责任、未按合同条款主张索赔，错失了合同赋予的权利。

4. 验收环节把关不严。未通过验收测试的交付物仍被签署通过，违反合同验收条款，使后续缺陷整改缺乏合同依据，也削弱了对供方的约束力。

5. 文档、培训和合同收尾要求在招标文件和合同中未充分体现，导致供应商认为文档和培训是“可选项”。

6. 缺乏变更控制机制。对供应商提出的范围外接口、数据迁移和定制开发要求未走正式变更流程，被迫被动接受追加金额。

二、改进措施：

针对工作说明书：

1. 在招标前组织业务部门、架构师、数据治理团队和运维负责人共同编写工作说明书，列出模块清单、技术指标、接口清单、数据标准、性能要求、验收标准和运维响应时间。

2. 将工作说明书与范围基准、需求文件和项目管理计划对照审查，确保范围、成本和进度信息一致。

3. 对潜在供方的澄清问题应统一书面回复，并将澄清结果作为招标文件的组成部分。

4. 在合同中明确文档交付清单、培训计划、验收步骤和试运行要求，避免“可选项”争议。

针对评标方法：

1. 复杂系统集成项目应采用综合评估法或性价比法，价格、技术、实施方案、资质业绩、运维服务和风险控制分别设置评分项。

2. 评标委员会应包含技术专家、财务专家和行业专家，并对评分细则进行保密和公正管理。

3. 对明显低于成本价的投标应要求其提供澄清说明，必要时否决其投标。

4. 合同签订前与中标人进行合同谈判，明确范围、交付物、验收条款、付款节奏和违约责任，避免中标后通过澄清和变更“塞私货”。

针对合同执行：

1. 建立合同执行跟踪表，按里程碑跟踪供方的进度、质量、成本和文档交付情况。

2. 出现延误或偏差时，应形成书面催告函，明确违约事实、合同条款依据、要求整改期限和法律后果。

3. 严格执行变更控制流程，供应商提出的范围外工作应提交正式变更申请，评估对成本、进度和质量的影响，经变更控制委员会审批后实施。

4. 合同款项支付应与里程碑验收结果挂钩，未通过验收的项目不得支付对应款项。

针对验收环节：

1. 验收应按合同验收条款执行，包括功能验收、性能验收、文档验收、培训验收和试运行验收。

2. 验收未通过的，项目经理应出具书面整改通知，要求供应商在限定期限内整改，整改完成前不得签署验收报告。

3. 涉及范围、进度和成本变化的，应同步更新项目管理计划和基准，并通知相关干系人。

4. 验收记录应包括验收依据、测试用例、测试结果、整改清单和最终结论，并归档保存。

三、采购合同收尾主要工作：

1. 完成所有交付物的最终验收，确认合同约定的产品、服务或成果全部交付。

2. 处理未决变更、索赔和争议，形成闭环清单并跟踪解决。

3. 办理合同款项结算，包括履约保证金退还、尾款支付和发票归档。

4. 开展供方履约评价，记录供方在质量、进度、成本和合作方面的表现。

5. 整理采购档案，包括招标文件、应答文件、评标记录、合同正文、变更文件、验收报告和往来函件。

6. 记录经验教训，包括工作说明书编写、评标方法选择、合同条款执行、风险处理和成本控制等方面的改进建议。

7. 在项目收尾报告中反映采购合同收尾结果，并通知相关干系人合同关闭。

8. 将供方信息、合同条款陷阱和应对方法纳入组织过程资产，供后续项目参考。

**踩分要点**：

1. 工作说明书问题应提到范围不清、技术指标缺失、接口与验收标准不明确、文档和培训未列入等关键点。

2. 评标方法问题应说明最低评标价法不适合复杂集成项目，应改用综合评估法或性价比法，并要求评标委员会组成合理。

3. 合同执行问题应提到书面催告、违约责任、变更控制流程、付款与验收挂钩等关键词。

4. 验收问题应强调未通过验收不得签字、整改通知必须书面、验收记录要完整归档。

5. 采购收尾应涵盖最终验收、争议闭环、款项结算、履约评价、档案归档、经验教训和组织过程资产更新。

6. 合同追加金额处理必须按变更控制流程，不能口头同意。

## 记忆口诀

采购过程口诀：规划采购先策划，实施采购选供方，控制采购督合同，收尾采购做总结。

合同类型口诀：范围清用总价，范围糊用成本，灵活用工料。

工作说明书口诀：模块接口要列清，技术性能写具体，验收标准必明确，文档培训列清单。

评标方法口诀：标准产品用最低，复杂集成综合评，性能价格看性价，低于成本要澄清。

合同执行口诀：里程碑验收挂钩，偏差书面催告，变更走流程，索赔按条款。

采购收尾口诀：最终验收要闭环，款项结算和档案，履约评价留记录，经验教训进资产。
