# 2026-07-23 软考（高级）系统架构设计师 第29次学习

## 今日核心概念

### 1. 算力网络与东数西算

定义：算力网络是以算为中心、网为根基、智为本质的新型信息基础设施，通过算力调度算法实现跨域算力（CPU/GPU/NPU/FPGA/ASIC）的统一度量、调度与供给。东数西算是国家战略，将东部高时延要求低的数据计算（AI训练/离线分析）调度到西部低成本算力中心。

关键要点：
- 算力三要素：算（CPU/GPU/NPU异构算力）+ 网（确定性网络/低时延/大带宽）+ 智（AI调度算法/意图驱动）
- 算力度量：FLOPS（理论峰值）+ MIPS（实际负载）+ IOPS（存储吞吐），需加权综合考虑CPU/内存/网络/存储
- 算力调度四步：感知（探测各节点算力）→ 抽象（统一算力模型）→ 编排（任务分解 + 调度策略）→ 执行（动态部署）
- 关键技术：SDN软件定义网络、SRv6确定性网络、算网大脑（统一编排）、算力路由（算力 + 网络联合寻路）
- 典型场景：AI训练（千卡集群/分布式并行/HPC）、科学计算（气象/生物/天文）、在线推理（低时延/边缘下沉）、数据备份归档
- 东数西算八大节点：京津冀、长三角、粤港澳、成渝、宁夏中卫、内蒙古和林格尔、贵州贵安、甘肃庆阳，构建一体化算力网

### 2. 大模型Agent与Multi-Agent系统

定义：大模型Agent是以LLM为核心，融合规划、记忆、工具使用能力的自治智能体。Multi-Agent是多智能体协同框架，多个Agent通过对话、协作、博弈完成复杂任务。

关键要点：
- Agent四要素：感知（输入解析/环境感知）+ 规划（任务分解/CoT思维链 + ReAct反思）+ 记忆（短期上下文 + 长期向量库）+ 工具（API/搜索引擎/代码执行/外部插件）
- ReAct范式：Reasoning推理 + Acting行动交替循环，每步先思考为什么做，再决定调哪个工具，最后观察结果
- Plan-and-Execute：先整体规划任务步骤（Plan），再逐步执行（Execute），适合长链路任务；vs ReAct实时反应更稳定
- Multi-Agent协作模式：监督者模式（Supervisor统一调度）、对等模式（Peer-to-Peer/自由对话）、流水线模式（顺序传递）、专家模式（领域专家组队）
- 主流框架：LangGraph（状态机/LangChain生态）、AutoGen（微软/对话驱动）、CrewAI（角色扮演/团队协作）、MetaGPT（SOP模拟软件公司）
- 关键挑战：幻觉控制（ReAct反思 + 工具验证）、上下文窗口限制（记忆压缩 + RAG检索）、Token消耗（按任务拆分 + 结果缓存）、安全对齐（工具白名单 + 输出审核）

### 3. 云原生AI平台MLOps与LLMOps

定义：MLOps是将DevOps理念应用于机器学习全生命周期（数据/训练/部署/监控）的工程实践。LLMOps是MLOps在大模型时代的特化，重点解决Prompt工程、模型微调、推理优化、效果评估等LLM特有工程问题。

关键要点：
- MLOps四阶段：数据工程（标注/特征/版本管理）→ 模型训练（实验跟踪/超参调优/分布式）→ 模型部署（CI/CD/灰度/A/B测试）→ 监控运维（漂移检测/性能下降告警/再训练触发）
- 模型注册中心：MLflow Model Registry存储模型版本/元数据/血缘，Databricks、Hugging Face Hub提供在线版本管理
- LLM专属工具链：Prompt管理（Prompt flow/版本对比）、评测（RAGAS/TruthfulQA/领域基准）、微调（LoRA/QLoRA/PEFT高效参数微调）
- 推理优化六招：量化（INT8/INT4/FP8）、剪枝（结构化/非结构化）、蒸馏（GPT-4到GPT-3.5）、KV Cache复用、连续批处理、PagedAttention分页注意力
- 模型服务化：Triton Inference Server（NVIDIA/多模型/动态批处理）、vLLM（PagedAttention/高吞吐）、Ollama（本地化部署）、LLama.cpp（CPU推理）
- 国产化LLMOps栈：ModelScope（阿里/魔搭）+ PAI（阿里云）+ 华为ModelArts + 百度BML + 讯飞星辰，构建国产全栈

### 4. 隐私计算与数据要素流通

定义：隐私计算是在保证数据可用不可见的前提下，实现数据价值的合规流通与协同计算的技术体系。是数据要素市场化配置的核心技术底座，解决数据隐私保护与价值挖掘的矛盾。

关键要点：
- 三大技术路径：联邦学习（数据不动模型动/横向纵向联邦）+ 安全多方计算MPC（密码学/不依赖可信第三方）+ 可信执行环境TEE（Intel SGX/Intel TDX/机密计算/硬件隔离）
- 联邦学习三态：横向（特征相同样本不同/跨地区银行）、纵向（样本相同特征不同/银行+电商联合建模）、迁移（样本特征都不同/跨行业迁移）
- 数据可信流通四件套：数据资产登记（区块链确权）+ 数据沙箱（隔离计算环境）+ 安全屋（脱敏后交换）+ 数据交易所（场内交易）
- 数据三权分置：数据资源持有权、数据加工使用权、数据产品经营权，分离促进流通
- 关键产品：蚂蚁摩斯（金融风控联邦学习）、微众FATE（开源联邦学习）、阿里DataTrust、华控清交PrivPy（清华/MPC）
- 法规框架：数据安全法（2021）、个人信息保护法（PIPL/2021）、数据出境安全评估办法、欧盟GDPR合规、HIPAA医疗数据

## 案例分析题

**题目**：某全国连锁零售企业拥有3000家门店、8000万会员、亿级SKU数据。为提升智能营销与精准推荐能力，计划建设基于大模型与隐私计算的智能营销平台。请从算力网络、LLMOps、隐私计算、Multi-Agent四个维度进行架构设计。

要求：
1. 算力调度与训练架构（5分）
2. LLM选型与微调策略（5分）
3. 联邦学习跨门店协同建模方案（5分）
4. Multi-Agent营销助手设计（5分）

**参考答案**：

1. **算力调度与训练架构（5分）**
- 采用东数西算架构：东部深圳门店端部署边缘推理节点（实时推荐RT < 50ms），西部贵州/宁夏部署千卡GPU训练集群（成本低/PUE 1.1）
- 使用RDMA无损网络 + 3.2Tbps IB互联，NVMe-oF共享存储，Checkpoint秒级保存
- 算力调度通过Kubernetes + Volcano + Volcano批调度，支持千卡并行、弹性扩缩容，训练任务优先级队列管理
- 推理层采用vLLM + Triton连续批处理，PagedAttention分页注意力，QPS提升5倍以上，GPU利用率从30%到80%
- 镜像分发：Dragonfly2+P2P加速，模型权重存OSS对象存储，通过EAS弹性推理服务部署

2. **LLM选型与微调策略（5分）**
- 基座模型：开源Qwen2-72B（阿里通义/中文强/可商用）或ChatGLM4-9B（清华/轻量快速），私有化部署保障数据不出域
- 微调策略：领域数据（商品库/营销话术/会员行为）做SFT监督微调，QLoRA 4bit量化 + LoRA低秩适配，单卡A100即可微调7B模型
- 强化学习：RLHF+DPO（直接偏好优化），用人类标注的优质营销回复做奖励模型，避免蒸馏奖励模型的失效
- 知识注入：RAG检索增强 + 知识图谱（商品SPU-SKU关系/会员标签），实时从向量库Milvus召回Top-K商品信息
- 评测体系：自动化指标（BLEU/ROUGE/事实性）+ 人工A/B测试（转化率/客单价/CTR），RAGAS评估RAG质量，建立回归测试集

3. **联邦学习跨门店协同建模（5分）**
- 纵向联邦学习：总部 + 区域门店，样本ID对齐（PSI隐私集合求交），总部训练共享模型 + 门店本地更新梯度
- 同态加密HE：Paillier加密梯度传输，SecureAggregation安全聚合，差分隐私DP加噪控制信息泄露
- 模型部署：联邦XGBoost（树模型联邦）做CTR点击率预测 + 联邦LR做风控反欺诈，各门店不出域
- 跨域连接：通过星脉隐私计算平台（蚂蚁/合规），各门店数据不出域情况下，联合训练推荐召回模型
- 激励层：数据贡献度度量（Shapley Value）+ 数据定价（按贡献付酬），区块链存证 + 数据资产登记

4. **Multi-Agent营销助手设计（5分）**
- 角色分工：营销策划Agent（活动创意/文案生成）+ 数据分析Agent（人群画像/效果归因）+ 推荐Agent（商品匹配）+ 客服Agent（对话兜底）
- 调度模式：Supervisor监督者模式，主Agent负责任务拆解、分发、汇总；MetaGPT风格SOP流程，先PRD后开发
- 工具调用：每个Agent独立工具集（QueryCoupon查券/SendMsg发送/SearchGoods搜商品/QueryOrder查订单），ReAct推理循环
- 记忆设计：短期（Redis会话上下文）+ 长期（Milvus用户向量记忆）+ 业务记忆（PostgreSQL会员标签表），多源融合
- 关键风控：审核Agent对所有营销文案做敏感词过滤、活动合规检查（反不正当竞争法）、领导讲话风格审核，确保不违规

**踩分要点**：
- 算力必答东数西算 + 千卡集群 + RDMA + 调度平台（Kubernetes/Volcano）
- LLM必答开源基座（Qwen/ChatGLM）+ QLoRA微调 + RAG + 评测体系
- 联邦学习必答纵向联邦 + PSI对齐 + 同态加密 + 安全聚合 + 差分隐私
- Multi-Agent必答角色分工 + Supervisor调度 + 工具调用 + 记忆设计 + 风控审核
- 每要点都展开为设计方案而非概念罗列，避免只写名词

## 记忆口诀

**算力网络三要素**：算（异构CPU/GPU/NPU）+ 网（SRv6确定性）+ 智（调度大脑），东数西算八节点（京津冀、长三角、粤港澳、成渝、宁夏内蒙、贵州甘肃）

**LLMOps四阶段**：数据（标注特征版本）+ 训练（实验分布式）+ 部署（CICD灰度AB）+ 监控（漂移下降告警）

**推理优化六招**：量化剪枝蒸馏 + KV Cache + 连续批处理 + PagedAttention分页

**联邦学习三态**：横向（特征同样本不同/跨地区）+ 纵向（样本同特征不同/银行电商）+ 迁移（都不同/跨行业）

**隐私计算三大路径**：联邦学习（数据不动模型动）+ MPC安全多方计算（密码学）+ TEE可信执行环境（SGX/TDX硬件隔离）

**数据三权分置**：持有权 + 加工使用权 + 产品经营权，分离流通

**国产LLM全栈**：Qwen2（基座）+ ModelScope魔搭（社区）+ PAI（云端）+ vLLM/Triton（推理） + 蚂蚁摩斯（联邦）
