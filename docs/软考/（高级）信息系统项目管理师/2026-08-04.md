# 2026-08-04 信息系统项目管理师学习内容（第39次）

## 今日核心概念

### 1. 项目进度管理网络计算
定义：关键路径法（CPM）通过网络逻辑图（PDM四关系FS/FF/SS/SF）计算每项活动的最早开始（ES）、最早完成（EF）、最晚开始（LS）、最晚完成（LF）时间，正向推算得ES/EF，反向推算得LS/LF，总浮动时间为零的路径即为关键路径。
关键要点：①四关系FS最常用/FF并行结束/SS并行开始/SF极少用；②浮动时间=LS-ES=LF-EF；③关键路径决定项目最短工期，可有多条；④关键路径上的活动浮动为零，任何延误都拖期；⑤资源约束下需资源平衡会改变关键路径；⑥进度压缩（赶工/快速跟进）需先识别关键路径。

### 2. 项目成本管理挣值分析
定义：挣值管理（EVM）通过整合范围、进度、成本三个维度，用计划值PV、挣值EV、实际成本AC三个中间变量，计算进度偏差SV/CPI、成本偏差CV/SPI、预测EAC/TCPI，实现项目绩效的客观度量与趋势预测。
关键要点：①三值关系PV基准/EV完成工作预算值/AC实际花费；②CV=EV-AC（成本偏差）、SV=EV-PV（进度偏差）；③CPI=EV/AC（成本绩效，>1节约）、SPI=EV/PV（进度绩效，>1提前）；④EAC四种计算公式：非典型BAC/CPI、典型BAC/(CPI×SPI)、双偏差、剩余重估；⑤TCPI=剩余工作/(BAC-EV)；⑥数据→信息→报告三级跳。

### 3. 项目质量管理七工具
定义：质量管理的七个基本工具（老七工具）包括因果图、流程图、帕累托图、控制图、相关图、直方图、散点图，用于质量问题的原因分析、过程监控和改进决策。
关键要点：①因果图找根因（鱼骨图4M1E人机料法环）；②流程图展示过程步骤；③帕累托图区分主次（80/20法则前几项主因）；④控制图判异（UCL/CL/LCL与七点法则）；⑤相关图看两变量关系；⑥直方图看分布形态；⑦散点图识别相关性；⑧新老七工具区分（老七偏静态统计，新七偏动态管理）。

### 4. 项目风险管理七过程组
定义：项目风险管理包括规划风险管理、识别风险、定性风险分析、定量风险分析、规划风险应对、实施风险应对、监督风险七个过程组，构成完整的风险闭环管理体系。
关键要点：①规划风险管理先定方法论与角色；②识别风险全员参与用鱼骨图/SWOT/核对单；③定性分析用概率影响矩阵打分排序；④定量分析用蒙特卡洛/EMV/决策树；⑤规划应对威胁四策略（规避/转移/减轻/接受）+机会四策略（开拓/分享/提高/接受）；⑥实施应对按计划执行；⑦监督风险做储备分析与审计；⑧风险登记册活文档持续更新。

### 5. 项目采购管理与合同类型
定义：项目采购管理包括规划采购管理、实施采购、控制采购、结束采购四个过程组，合同类型分为总价合同（FFP/FP）、成本补偿合同（CPFF/CPIF/CPAF/CPPC）和混合型合同（T&M），不同合同类型在风险分担和成本控制上各有优劣。
关键要点：①FFP风险全在卖方，范围必须清楚；②CPFF卖方收回成本加固定费用，风险在买方；③CPIF按成本绩效激励，奖励节约；④CPAF按成本百分比激励；⑤T&M临时性/小项目/资源不足补充；⑥索赔管理四阶段（提出→核实→答复→仲裁/诉讼）；⑦采购审计在合同收尾时进行；⑧自制外购分析（成本/能力/风险三角）。

## 案例分析题

**题目**：
某省级"智慧人社"数字化转型项目，总投资5200万元，工期18个月，覆盖社保、就业、人才服务三大业务域共12个子项目，由A公司总包承建。项目采用敏捷+瀑布混合开发模式，团队规模60人分布在沈阳、北京两地。
项目执行至第9个月时发生以下情况：
1. 项目经理小张发现CV=-300万元、CPI=0.75、SPI=0.85，已向发起人书面报告两次，但发起人未做批示也未追加预算，小张口头承诺客户"11月必须上线"；
2. 第10个月初，关键路径上的"社保核心业务系统"接口开发团队3名核心成员同时提出离职，其中架构师老李离职导致接口设计文档无人能讲清楚；
3. 采购部新增应急采购一笔"应用监控软件"80万元，采用单一来源方式直接采购，未走招标流程；
4. 客户CIO在第10月评审会上要求新增"跨省通办"功能模块，预计增加500万成本和3个月工期，但A公司商务经理口头答应"做"，未提交变更申请；
5. 第12月测试阶段缺陷率高达8.7%，远高于行业基准2%，项目经理使用帕累托图分析发现80%缺陷集中在"社保参保接口"和"就业人才数据共享"两个模块；
6. 第15月项目延期3个月，社保局要求按合同条款"延期一天扣合同额万分之五"累计扣款235万元，A公司提出此为"不可抗力"拒绝扣款；
7. 项目交付后3个月运行期，社保核心系统在月末批量处理时崩溃，导致200万参保人无法查询参保信息，A公司运维人员2小时后才到达现场。

请分析：
（1）挣值计算与预测，请计算EAC（典型偏差）和TCPI值；
（2）按风险七过程组分析上述风险事件并指出缺失环节；
（3）该项目的质量管理存在什么问题，应如何改进；
（4）变更管理、采购管理、合同收尾三个环节分别存在哪些违规。

**参考答案**：

（1）挣值计算与预测：
- CV = EV - AC = -300万元（成本超支300万）
- CPI = EV/AC = 0.75
- SPI = EV/PV = 0.85
- 典型偏差EAC = BAC / (CPI × SPI) = 5200 / (0.75 × 0.85) = 5200 / 0.6375 ≈ 8157万元
- TCPI = (BAC - EV) / (BAC - AC) = 剩余工作 / 剩余资金，按BAC重估：TCPI ≈ 2.94（极高，后续必须严格控制成本）
- 项目失控严重，应立即启动整体重估和储备金申请

（2）风险七过程组分析：
- 规划风险管理：缺失整体风险方法论与责任人；
- 识别风险：核心架构师单点依赖未识别为风险（应为人才风险登记）；
- 定性分析：未对人员流失风险打分排序；
- 定量分析：无EMV或蒙特卡洛支持；
- 规划应对：未制定关键岗位备份和知识转移策略；
- 实施应对：采购监控软件属应急但无应急储备；
- 监督风险：无储备分析和技术绩效跟踪；
- 缺失闭环：核心人员流失后无缓解策略。

（3）质量管理问题：
- 问题：缺陷率8.7%远高于基准2%，说明测试和质量保证严重缺失；测试策略不当（仅功能测试无性能/安全）；质量标准未在前期规划；缺陷修复未按变更控制；测试独立性不足（开发自测）；
- 改进：建立质量三层次（规划定标准/保证审过程/控制抓缺陷）；引入测试四层次三策略（单元/集成/系统/验收）；采用帕累托图主因（社保接口+数据共享）优先整改；引入老七工具（控制图监控过程稳定）；老李文档化交班演练。

（4）三环节违规：
- 变更管理违规：商务经理口头答应新增模块（500万+3月）未走变更流程；应提交CCB评估影响（成本/进度/范围/质量）走整体变更控制五步流程（识别→评估→CCB审批→实施→验证）；
- 采购管理违规：80万单一来源采购未走招标程序（违反招标投标法，金额超20万必须招标或比选）；应补走比选/磋商流程并完善采购审计；
- 合同收尾：扣款争议属于合同索赔争议，"不可抗力"认定需提供证据链（合同条款+气象/疫情等证明+30天内提交书面通知）；A公司拒绝扣款但应通过合同条款核实（不可抗力需事先定义且及时通知），建议按合同争议解决程序（协商→调解→仲裁/诉讼）；运行期崩溃属运维责任，按SLA违约追溯（响应时间、可用性指标）。

**踩分要点**：
1. 挣值计算公式必须列明（CV/SV/CPI/SPI/EAC/TCPI六公式），典型偏差EAC=BAC/(CPI×SPI)
2. 风险管理按七过程逐一指明缺失（规划/识别/定性/定量/规划应对/实施/监督）
3. 质量管理问题答三层次（规划定标/保证审过程/控制抓缺陷）+老七工具应用（帕累托/控制图/鱼骨图）
4. 变更管理违规格式化（CCB五步流程：识别→评估→审批→实施→验证）
5. 采购违规引用法规（招投标法：20万以上必须招标）
6. 合同扣款按"不可抗力四要件"+及时通知义务分析
7. 运维响应时间按SLA条款追责

## 记忆口诀
1. 进度四关系：FS最常用、FF并行终、SS并行始、SF几乎不用
2. 关键路径口诀：浮动时间为零是关键，多条关键取最长
3. 挣值三值：PV计划值是预算，EV挣值已完成，AC实际花了多少
4. 挣值四公式：CV=EV-AC、SV=EV-PV、CPI=EV/AC、SPI=EV/PV
5. EAC四种记：非加典除双乘除、重估重头来（BAC/CPI；BAC/(CPI×SPI)；CPI×SPI分母；剩余重估）
6. 老七工具：因果流程帕累托、控制相关直方散（因帕控流核直散）
7. 帕累托法则：80%问题由20%原因造成
8. 控制图七点：连续7点同侧判异常
9. 风险七过程：规划识别定性强、定量规划实施监（规矩定计识定定应施监）
10. 风险应对威胁四策：规避转移减轻加接受
11. 风险应对机会四策：开拓分享提高加接受
12. 合同三类型：FFP总价风险买方轻、CPFF成本加固定、T&M混合按时间材料
13. 采购四过程：规划实施控制收（规实控关）
14. 索赔四阶梯：提出核实答复诉讼/仲裁（一提二报三答复）
15. 变更五步法：识别评估CCB审、实施更新收（识别→评估→CCB→实施→验证）
16. 质量三层次：规划定标准、保证审过程、控制抓缺陷
17. 不可抗力四要件：客观情况、不能预见、不能避免、不能克服+及时通知+30日内出示证明
18. SLA三要素：可用性、响应时间、解决时间
19. 知识转移：文档化+交叉培训+独立演练+AB角备份
20. 缺陷修复流程：记录→分类→归因→修复→验证→关闭
