## 今日核心概念

### 1. 项目成本管理过程组与预算结构

定义：项目成本管理是为确保项目在批准的预算内完成而开展的估算、预算、控制与融资活动的全过程，涵盖规划成本管理、估算成本、制定预算、控制成本四大过程。

关键要点：
- 成本基准是经批准的、按时间分布的项目预算，是成本控制的依据
- 成本基准+管理储备=项目预算；管理储备不纳入成本基准，使用须经变更控制
- 估算精度随项目生命周期由粗到细：粗略量级估算±50%、确定性估算±10%、详细估算±5%
- 成本管理与范围、进度、风险、资源联动，单一要素调整必触发综合影响分析
- 融资决策需考虑现金流、支付节奏、币种、税务与汇率风险

### 2. 成本估算方法

定义：成本估算是对完成项目活动所需货币资源进行近似估算的过程，输出活动成本估算与估算依据。

关键要点：
- 类比估算（自上而下）：基于历史相似项目，快速但精度低，适合早期
- 参数估算：基于历史数据与统计关系（如单价×数量），精度较高，需可靠模型
- 三点估算：基于最可能成本（CM）、最乐观成本（CO）、最悲观成本（CP），期望值=（CO+4CM+CP）/6，标准差=（CP-CO）/6
- 自下而上估算：分解到工作包后汇总，最准确但耗时，适合详细规划阶段
- 储备分析：估算时需识别应急储备（应对已知-未知风险）与管理储备（应对未知-未知）
- 决策：类比用于早期粗估，参数用于规模化，自下而上用于最终预算，三点估算用于风险分析

### 3. 成本预算与资金需求计划

定义：成本预算是把估算出的总成本逐期分配到项目各个时间阶段，形成成本基准并输出资金需求计划的过程。

关键要点：
- 输出：成本基准（时间分布的S曲线）+ 项目资金需求（按周/月/季）
- 必须覆盖全部工作的预算，包括应急储备；管理储备单列不分配到时间
- S曲线反映计划支出节奏，与挣值曲线对比可识别进度偏差
- 资金需求计划须与采购合同支付节点、里程碑验收、发票流程对齐
- 预算一经变更控制流程批准即形成成本基准，任何修改须走整体变更控制

### 4. 成本控制与挣值管理

定义：成本控制是监督成本执行情况、识别偏差、分析原因并实施纠偏的过程，挣值管理是综合范围、进度、成本的三维测量方法。

关键要点：
- 三大指标：PV（计划值）、EV（挣值）、AC（实际成本）
- 四大偏差：CV=EV-AC（成本偏差）、SV=EV-PV（进度偏差）
- 四大绩效指数：CPI=EV/AC（成本绩效）、SPI=EV/PV（进度绩效）
- 预测公式：EAC=BAC/CPI（典型偏差）、ETC=EAC-AC、VAC=BAC-EAC、TCPI=(BAC-EV)/(BAC-AC)
- 偏差分析须配合因果识别，避免仅看数字不追根因
- 控制工具：成本变更控制系统、挣值分析、绩效审查、预测、储备分析、趋势分析
- 完工尚需绩效指数TCPI>1.0表示后续工作须比当前更高效才达BAC

### 5. 成本超支纠偏与融资策略

定义：在发现成本超支后，通过变更范围、压缩成本、追加预算、改善效率、优化融资等多策并举，使项目回归可承受成本目标的系统化应对。

关键要点：
- 范围调整：范围缩减是最直接手段，但可能影响收益
- 成本压缩：采购谈判、招标竞争、资源替代、技术替代、流程优化
- 进度-成本联动：赶工增加成本，快速跟进增加风险
- 储备动用：应急储备由项目经理审批，管理储备须变更流程
- 融资策略：分期付款、里程碑验收付款、运营服务付费（PaaS/SaaS）
- 决策依据：完工估算EAC、完工尚需指数TCPI、收益再评估
- 重大成本决策须走CCB审批并启动商业论证复审

## 案例分析题

**题目**：某市"智慧市场监管"一体化平台建设项目，总投资5200万元，工期18个月，采用预测型开发模式，分为市场主体监管、风险预警、执法协同、决策支持四大子系统。项目第8个月初进行绩效审查，相关数据如下：

- 第8个月初PV（计划值）=2400万元
- 第8个月初EV（挣值）=2080万元
- 第8个月初AC（实际成本）=2600万元
- BAC（完工预算）=5200万元
- 至第8个月初，已累计动用应急储备180万元

项目实施过程中还出现以下问题：
1. 项目启动时未制定成本管理计划，仅由财务人员按年度预算简单切分成本基准，缺乏按工作包的成本分解和资金需求计划；
2. 因决策支持子系统需求频繁变更，团队连续加班赶工，同时承接3个并行变更未做综合影响分析，导致已完成的预测分析模块在第7个月返工重做；
3. 系统集成商在第6个月提出因硬件涨价（GPU单价上涨40%）追加800万元采购款，项目经理为不耽误进度口头同意，未走变更控制流程；
4. 项目经理每月仅向领导汇报"按计划推进"，未输出CV/SV/CPI/SPI等挣值数据；财务部门反映预算执行率与项目实际进度严重不符；
5. 风险登记册中"硬件价格波动"风险未明确应对策略和触发阈值，直到供应商书面提出涨价才被动应对；
6. 项目第8个月初预测EAC为6200万元，超出BAC约1000万元，但CCB未召开专题会议审查该偏差。

请根据以上案例，回答以下问题：

一、请计算第8个月初的CV、SV、CPI、SPI、当前TCPI，并判断项目成本与进度绩效。

二、按当前绩效计算EAC和VAC，分析继续按原BAC完工的可行性。

三、请从成本管理计划、变更控制、储备管理、挣值分析、风险应对五个维度，指出本项目存在的主要问题。

四、请给出项目组应采取的改进与纠偏措施。

**参考答案**：

一、绩效计算与分析：
- CV = EV - AC = 2080 - 2600 = -520万元（CV<0，成本超支）
- SV = EV - PV = 2080 - 2400 = -320万元（SV<0，进度滞后）
- CPI = EV/AC = 2080/2600 = 0.80（每花1元仅完成0.80元工作，成本绩效差）
- SPI = EV/PV = 2080/2400 ≈ 0.867（进度绩效不佳，只完成约86.7%计划工作）
- 当前TCPI（按BAC）= (BAC-EV)/(BAC-AC) = (5200-2080)/(5200-2600) = 3120/2600 = 1.20
- 综合判断：项目处于"成本超支+进度滞后"双重不利状态（CPI=0.80<1，SPI=0.867<1），且TCPI=1.20说明后续工作须比当前更高效20%才能按BAC完工，难度极大。

二、完工预测与可行性：
- EAC（典型偏差）= BAC/CPI = 5200/0.80 = 6500万元
- VAC = BAC - EAC = 5200 - 6500 = -1300万元
- 即项目最终可能超支约1300万元，超支比例约25%
- 若考虑已动用应急储备180万元，剩余应急储备亦将耗尽；继续按BAC完工可行性低，必须启动变更控制与商业论证复审。

三、主要问题分析：

（一）成本管理计划缺失问题
- 未制定成本管理计划，无成本度量单位、精度等级、测量规则与报告频率
- 成本基准未按工作包分解到时间阶段，缺乏可执行的资金需求计划
- 财务按年度切分而非按项目阶段切分，无法支撑挣值分析与偏差识别

（二）变更控制失控问题
- 集成商追加800万元采购款口头同意，未提交正式变更申请
- 未做综合影响分析，未由CCB审批，违反合同与变更控制流程
- 决策支持子系统3个并行变更同时承接，缺少变更优先级排序
- 变更后未更新成本基准、范围基准、采购合同与进度计划

（三）储备管理不当问题
- 风险登记册中"硬件价格波动"未设触发阈值与应对策略
- 应急储备动用180万元未履行必要的审查与监控流程
- 管理储备单列但未启动补充，触发条件模糊
- 风险发生后被动应对而非主动储备

（四）挣值分析缺失问题
- 每月仅汇报"按计划推进"，未输出CV/SV/CPI/SPI等关键指标
- 财务预算执行率与项目实际进度脱钩，财务与项目管理两张皮
- 未建立趋势分析与预测机制，偏差发现滞后
- 未通过挣值曲线（S曲线）直观识别进度与成本偏差

（五）风险应对失守问题
- 硬件涨价等供应链风险未提前识别与定量评估
- 应急储备动用频繁但未复审风险触发条件
- 风险登记册动态更新不到位，应对策略与责任人缺失
- 重大偏差出现后未启动商业论证复审，治理委员会失守

四、改进与纠偏措施：

第一，立即召开CCB专题会议，重新审查当前成本偏差（EAC=6500万 vs BAC=5200万），决定继续/调整/暂停/终止，决策结果书面化。

第二，按成本管理计划样板重做成本管理计划，明确度量单位、精度等级、控制阈值、报告频率（建议周报）、审计周期。

第三，将已发生的口头变更（800万追加采购款）补录为正式变更申请，重新做范围/进度/成本/质量/资源/风险/采购八维度影响分析。

第四，对决策支持子系统3个并行变更进行优先级排序，必要时取消或推迟低价值变更，回退范围蔓延。

第五，建立按工作包的成本分解与按周/月的资金需求计划，与采购合同支付节点和里程碑验收挂钩。

第六，每周输出挣值分析报告（CV/SV/CPI/SPI/EAC/VAC/TCPI），每月向治理委员会汇报，重大偏差即时预警。

第七，引入应急储备审查机制：动用前需评估风险触发原因、剩余储备、影响范围；动用后须更新风险登记册与成本基准。

第八，启动管理储备评估：若EAC持续超出BAC+应急储备，须变更流程动用管理储备或追加预算。

第九，更新风险登记册，对供应链价格波动、政策调整、人员流动等高影响风险制定明确应对策略与触发阈值。

第十，谈判追加成本分摊机制：与集成商谈判追加款的支付条件、里程碑验收挂钩、降价或服务替代方案。

第十一，对预测分析模块返工案例进行根因分析，建立变更评审与影响分析模板，避免类似返工。

第十二，建立财务与项目一体化管理机制，财务预算执行率与项目挣值数据联动，月度对账审计。

第十三，启动商业论证复审：重新评估项目ROI、净现值、战略一致性、必要性与可承受性，决策结果报治理委员会。

第十四，加强采购合同管理，明确价格调整条款（价格波动上限、分摊比例、终止条件），减少被动追加。

**踩分要点**：

一、CV、SV、CPI、SPI、TCPI五个指标必须准确计算，结果带单位（万元），绩效判断须双指标并进。

二、EAC=6500万元（典型偏差公式BAC/CPI）、VAC=-1300万元，须明确"按BAC完工可行性低"。

三、TCPI=1.20>1说明后续须更高效，TCPI计算用(BAC-EV)/(BAC-AC)而非其他形式。

四、问题分析须覆盖成本管理计划/变更控制/储备管理/挣值分析/风险应对五大维度，每维度至少2-3个具体问题。

五、必须指出"财务按年度切分而非按阶段切分"导致挣值无法开展。

六、口头同意追加800万元、未走CCB是典型越权变更，必须补录正式变更申请并做八维度影响分析。

七、应急储备动用须走审查流程，管理储备须变更流程，二者不可混用。

八、汇报"按计划推进"而不输出挣值指标是典型管理失职，须建立周报/月报制度。

九、风险登记册无触发阈值与应对策略是典型风险失守，须建立动态更新与复审机制。

十、CCB未召开专题会议审查EAC=6500万的重大偏差是治理失守，必须立即召开并形成书面决策。

十一、纠偏措施必须覆盖短期（变更控制/赶工）与长期（商业论证复审/范围调整/融资优化）两个层次。

十二、采购合同价格调整条款缺失是制度性问题，须在合同模板中固化。

十三、决策支持子系统3个并行变更同时承接，缺少优先级排序与影响分析，必须回退或排序。

十四、应急储备动用180万元未履行必要的审查与监控流程，是储备管理失控的具体表现。

十五、根因分析与教训总结必须形成组织过程资产，避免类似问题重复发生。
