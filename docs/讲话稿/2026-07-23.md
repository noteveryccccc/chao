# 在全市"人工智能+"行动暨数字经济高质量发展推进会上的讲话

**（2026年7月23日）**

同志们：

今天我们召开这次会议，主要任务是深入贯彻落实党中央、国务院关于加快发展数字经济和推进"人工智能+"行动的决策部署，按照省委、省政府工作要求，动员全市上下抢抓新一轮人工智能发展机遇，加快培育新质生产力，推动数字经济高质量发展，为打好三季度攻坚战、圆满完成全年目标任务提供强劲动能。刚才几位同志作了发言，讲得都很好。下面，我讲三点意见。

## 一、认清形势，深刻把握人工智能赋能产业发展的战略机遇与面临的现实挑战

党的十八大以来，党中央、国务院高度重视人工智能发展，习近平总书记多次作出重要指示，强调要"推动人工智能与实体经济深度融合，培育新质生产力"。从全国大局看，人工智能已成为重组全球要素资源、重塑产业竞争格局的战略引擎。从我市发展实际看，数字经济已成为推动高质量发展的重要支撑。

过去一年多，全市上下锚定数字经济发展目标，加压奋进、攻坚突破，取得了阶段性成效。一是数字产业能级持续跃升。全市数字经济核心产业增加值达到386亿元，同比增长13.6%，占GDP比重提升至15.2%；集成电路、工业机器人、智能终端等核心产业增速分别达到21.3%、18.6%和16.8%，人工智能相关企业达到628家，其中国家级专精特新"小巨人"36家。二是基础设施支撑更加坚实。累计建成5G基站9260座，实现城区和重点园区全覆盖；千兆光纤入户率达到76.8%，居全省前列；算力中心标准机架超过1.86万架，智算占比达到38.6%，"算力底座"初步成型。三是融合应用场景加快拓展。规上工业企业关键工序数控化率达到72.6%，数字化研发设计工具普及率达到86.8%；累计打造省级"5G+工业互联网"示范项目48个、"AI+"标杆场景86个，2个项目入选国家人工智能典型案例。四是数据要素市场稳步破冰。公共数据开放共享平台累计归集数据18.6亿条，向社会开放数据接口286个；东北大数据交易中心累计交易额突破5200万元，位居全省前列。

在肯定成绩的同时，也要清醒看到，对标先进地区、对比发展需求，我市人工智能赋能产业发展仍面临不少突出短板。一是核心产业规模偏小。我市人工智能企业数量虽已达628家，但多为中小企业，行业领军企业仅6家，缺少像科大讯飞、商汤科技那样的本土头部企业；核心算法、高端芯片、智能传感器等关键环节对外依存度超过65%，自主可控能力亟待提升。二是企业应用积极性不高。规上工业企业人工智能技术应用率仅32.6%，低于先进地区18个百分点以上；中小企业受资金、人才制约，"不敢用、不会用、用不起"问题较为普遍。三是数据要素流通不畅。政务数据共享率只有68.6%，公共数据与社会数据融合度不高，数据交易所交易活跃度偏低，"数据孤岛"问题尚未根本破除。四是专业人才结构性短缺。全市人工智能领域高端人才仅326人，缺口超过1.86万人；本地高校人工智能相关专业设置偏少，校企合作、产教融合渠道不够畅通，留人用人环境仍需优化。五是安全治理体系尚不健全。算法歧视、数据滥用、隐私泄露等风险隐患不同程度存在，覆盖事前、事中、事后全过程的监管机制还不够完善。

同志们，机遇稍纵即逝，挑战不容回避。我们必须把思想和行动统一到习近平总书记重要指示精神和党中央决策部署上来，统一到省委、省政府工作要求上来，以坐不住、等不起、慢不得的紧迫感，凝心聚力推动"人工智能+"行动各项任务落地见效，努力在数字经济新赛道上抢占先机、走在前列。

## 二、聚焦重点，全力推动"人工智能+"行动各项任务落地见效

做好下步工作，总的思路是：以习近平新时代中国特色社会主义思想为指导，深入贯彻党中央、国务院关于数字经济发展的决策部署，按照"夯基础、强产业、促融合、优治理"的总体要求，实施"人工智能+"六大行动，加快构建数字经济高质量发展新格局。工作中要重点抓好以下五个方面：

**第一，实施"AI+产业升级"行动，赋能制造业提质增效。** 聚焦全市装备制造、原材料、轻工食品等优势产业，组织实施"千企智改数转绿转"工程，年内推动186家企业开展人工智能技术改造，新培育省级智能工厂和数字化车间36家，争创国家级智能制造示范工厂3家以上。围绕集成电路、工业机器人、新能源汽车、生物医药等重点产业链，组建"AI+产业链"联合创新体，每个产业链梳理不少于20个典型应用场景，推动人工智能技术全流程、全环节嵌入。加快推动人工智能与研发设计、生产制造、质量管理、供应链协同深度融合，力争规上工业企业关键工序数控化率达到78%以上，数字化研发设计工具普及率达到92%以上。

**第二，实施"算力基础设施"夯基行动，强化数字底座支撑。** 抢抓全国一体化算力网建设机遇，加快推进全市算力枢纽节点建设，年底前新增标准机架8000架以上，智算规模占比提升至45%以上。推动5G、千兆光网深度覆盖，年内新建5G基站1200座，实现重点园区、重点镇街全覆盖；加快布局"5G+工业互联网"二级解析节点，推动更多工业企业"上云用数赋智"。推进物联网感知设施统一部署、统一管理，加快建设市级物联感知中台，年内终端接入量突破860万。扎实做好网络和数据安全保障，加快市级数据安全监测平台升级扩容，筑牢数字经济安全防线。

**第三，实施"数据要素价值释放"行动，培育数据流通市场。** 加快推进公共数据资源开发利用，年内推动市县两级政务数据共享率达到85%以上，向社会开放公共数据集200个以上。健全数据要素流通制度，完善数据登记、评估、交易、分配全链条服务，推动东北大数据交易中心年交易额突破1亿元。培育数据要素市场主体，引进和培育数据服务商20家以上，打造一批数据要素应用"样板间"。探索建立数据资产入表、收益分配、数据安全治理等机制，充分释放数据要素的乘数效应。

**第四，实施"AI+企业培育"行动，壮大产业发展群体。** 实施人工智能企业"育苗造林"工程，建立"种子企业—瞪羚企业—领军企业"梯次培育体系，年内新培育人工智能领域种子企业60家、瞪羚企业18家、领军企业3家。聚焦算法、算力、数据、应用四大方向，加大招商引资力度，依托驻外招商联络处、京津冀、长三角、粤港澳大湾区等重点区域，年内新引进人工智能优质项目80个以上，其中亿元以上项目不少于20个。支持本地人工智能企业做大做强，鼓励有条件的企业参与国家标准、行业标准制定，提升我市人工智能产业的话语权和影响力。

**第五，实施"AI+民生服务"行动，赋能治理能力提升。** 聚焦教育、医疗、养老、交通、政务服务等重点领域，推动人工智能场景化落地，打造一批可复制、可推广的标杆应用。深化"一网通办"改革，推动更多高频事项"智能审批""秒批秒办"，年内新增智能审批事项120项以上；强化12345政务服务热线智能化升级，引入大模型技术提升诉求响应效率和办理质量。探索建设"城市智能体"，打通城市运行、公共安全、生态环保、应急管理等重点领域数据壁垒，构建"一屏统揽、一网统管"的城市治理新格局。同步推进适老化改造和数字素养提升，让数字经济成果惠及更多群众。

**第六，实施"AI人才引育"行动，夯实智力支撑。** 编制发布全市人工智能人才需求目录，瞄准算法工程师、架构师、产品经理等紧缺岗位，实施"AI领航"招才引智计划，年内引进人工智能领域高层次人才200人以上。深化产教融合、校企合作，支持在沈高校加快建设人工智能学院、人工智能产业学院，定向培养复合型人才；依托重点企业建设一批实训基地，年内培训人工智能技术应用人才1万人次以上。完善人才服务保障，在住房、配偶就业、子女入学、医疗保健等方面提供"一站式"服务，让各类人才在沈安心创业、舒心生活。

## 三、强化保障，确保"人工智能+"行动各项部署落实落地

一分部署，九分落实。各级各部门要切实增强责任感、使命感、紧迫感，凝心聚力、真抓实干，以过硬作风推动各项任务落地见效。

**一要压实工作责任。** 各级党委、政府要将"人工智能+"行动摆在突出位置，主要负责同志亲自抓、分管负责同志具体抓。市级层面已经成立"人工智能+"行动领导小组及工作专班，各级各有关部门也要健全相应工作机制，明确责任分工，细化目标任务，确保层层有人抓、事事有人管。市级各牵头部门要抓紧制定配套实施方案，明确时间表、路线图；各县（市）区、开发区要结合实际，制定具体落实举措，确保上下贯通、执行有力。

**二要强化要素保障。** 市财政要统筹专项资金，设立"人工智能+"产业发展母基金，首期规模8亿元，县（市）区、开发区配套设立子基金，构建覆盖种子期、初创期、成长期、成熟期的全周期基金体系。强化用地、用能、数据保障，对人工智能重点项目用地优先纳入国土空间规划，对数据中心合理配置能耗指标，对数据要素流通给予制度性安排。充分发挥金融赋能作用，引导金融机构开发"AI贷""算力贷"等专属产品，年内人工智能领域新增贷款规模突破120亿元。

**三要优化营商环境。** 全面落实公平竞争审查制度，保障各类市场主体平等参与人工智能产业竞争。深化"放管服"改革，开通人工智能项目审批"绿色通道"，推行容缺受理、并联审批，企业开办全流程压减至0.5个工作日办结。强化知识产权保护，依法严厉打击侵犯知识产权和商业秘密违法行为，营造鼓励创新、宽容失败的良好生态。完善政企沟通机制，市级领导同志带头联系重点人工智能企业，面对面听意见、实打实解难题。

**四要健全考核督导。** 将"人工智能+"行动核心指标纳入各级党政领导班子和领导干部综合考核体系，权重不低于8%，对工作进展滞后的县（市）区和部门，及时预警通报、限期整改。强化跟踪问效，市领导小组办公室要建立"月调度、季通报、年考评"工作机制，对重大任务、重大项目、重大改革实行台账管理、闭环落实。强化督查激励，对真抓实干、成效显著的单位和个人给予表彰奖励，对推诿扯皮、消极应付的依规依纪问责。

**五要营造浓厚氛围。** 各级宣传部门要全方位、多角度宣传"人工智能+"行动的政策措施、进展成效、典型案例，讲好"AI+沈城"故事，营造全社会关心支持人工智能发展的浓厚氛围。鼓励高校、科研院所、行业协会、龙头企业举办人工智能高端论坛、创新创业大赛、场景对接会等活动，激发全社会创新创造活力。广泛开展人工智能科普教育和技能培训，提高全民数字素养，让人工智能真正走进机关、企业、社区、校园，走进千家万户。

同志们，人工智能是新质生产力的重要引擎，数字经济是高质量发展的重要支撑。让我们更加紧密地团结在以习近平同志为核心的党中央周围，以"时不我待、只争朝夕"的精神状态，以"踏石留印、抓铁有痕"的工作劲头，凝心聚力、扎实工作，加快推动"人工智能+"行动落地见效，为打好三季度攻坚战、开创全市高质量发展新局面作出新的更大贡献！

谢谢大家。
