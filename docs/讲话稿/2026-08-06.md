# 在全市招商引资和项目建设秋季攻坚动员会上的讲话

**（2026年8月6日）**

同志们：

今天召开全市招商引资和项目建设秋季攻坚动员会，主要任务是深入贯彻落实党中央、国务院关于稳投资、扩内需、促发展的决策部署，全面落实省委、省政府关于打好三季度经济工作攻坚仗的工作要求，动员全市上下抢抓三季度施工黄金期，凝心聚力、尽锐出战，迅速掀起秋季招商引资和项目建设新攻势、新高潮，以高质量招商和高效率项目支撑全市经济社会高质量发展。招商引资是经济工作的"生命线"，项目是稳增长的"压舱石"。当前，距离年底仅剩不到五个月时间，全市各级各部门要把思想和行动统一到市委、市政府决策部署上来，以坐不住、等不起、慢不得的紧迫感，以敢攻坚、善突破、勇争先的精气神，大干三季度、决胜下半年，确保全年各项目标任务圆满完成。

## 一、认清形势任务，切实增强打好秋季攻坚战的责任感紧迫感

一要清醒认识完成全年目标的严峻挑战。今年以来，全市经济运行总体平稳，但稳的基础还不够牢固，进的势头还不够强劲。受外部环境复杂变化、市场需求恢复不及预期、部分行业价格低迷等多重因素影响，全市主要经济指标与年初目标、与兄弟市相比仍有一定差距。特别是投资增速放缓、签约项目落地不快、在建项目推进不快等问题，直接影响全年目标完成。打好秋季攻坚战，是稳住经济大盘、完成全年目标的迫切需要，是补课赶队、扭转被动局面的关键一招，必须以更大力度、更实举措，集中精力、集聚资源，推动招商和项目建设实现突破性进展。

二要清醒认识三季度施工的窗口效应。三季度是项目建设的黄金期、招商引资的活跃期、立秋后的施工期。这一时期，气温适宜、雨季接近尾声、原材料供应稳定，是户外施工、厂房建设、设备安装的最佳时间窗口。同时，国家和省级层面正在加快推动一揽子增量政策落地，超长期特别国债、新型政策性金融工具、专项债项目扩容等政策利好集中释放，为我们争取资金、谋划项目、加快建设提供了难得机遇。全市各级各部门必须增强敏锐性，把握规律、用好政策、抢抓进度，把三季度这一宝贵窗口期转化为推动发展的黄金期，把政策红利转化为实实在在的项目和投资。

三要清醒认识区域竞争的现实压力。百舸争流、奋楫者先。当前各地都在拼经济、抓项目、抢招商，竞争异常激烈。项目等不来、要不来，必须靠我们去争、去拼、去抢。我们必须破除"小进即满、小成即安"的自满心态，破除"按部就班、四平八稳"的保守心态，破除"等靠要看、推拖绕躲"的惰性心态，以思想破冰引领行动突围，以作风提升推动工作落实，确保在区域竞争中不掉队、在新一轮发展中争上游。

## 二、聚焦攻坚重点，推动招商引资和项目建设实现新突破

一要着力在"招大引强"上求突破。要立足全市产业基础、资源禀赋和比较优势，围绕装备制造、新材料、新能源、生物医药、数字经济、现代物流等重点产业，紧盯世界500强、国内500强、央企和行业领军企业，绘制产业链招商图谱，编制目标企业清单，开展定向招商、精准招商、以商招商。要创新招商方式，灵活运用资本招商、基金招商、飞地招商、平台招商、场景招商等新模式，吸引更多优质项目落户。要强化招商考核，坚持"招得来、落得下、建得快、见实效"导向，把合同履约率、资金到位率、开工投产率作为重要指标，坚决杜绝"数字招商""签约不落地"等问题。年内，要确保全市新引进亿元以上项目不少于XXX个，其中10亿元以上项目不少于XX个，50亿元以上项目实现新突破。

二要着力在"项目推进"上求突破。要对省市重点项目、亿元以上在建项目实行清单化管理、挂图作战，建立"周调度、月通报、季考评"推进机制，逐项目明确时间表、路线图、责任人，倒排工期、挂图作战。要强化要素保障，聚焦用地、用工、融资、审批等关键环节，逐项梳理、逐项破解，打通项目推进的堵点难点。要加快推进未开工项目，对项目用地、规划、环评、资金等前置条件逐一梳理，推动项目早开工、快建设；对进度滞后项目，要查找原因、分类施策，挂牌督办、跟踪问效；对竣工项目，要加快验收、投产、达效，确保形成更多实物工作量。年内，省市重点项目开工率、投资完成率要达到预期目标，年度投资完成额较上年增长XX%以上。

三要着力在"园区承载"上求突破。园区是项目落地的主阵地、产业集聚的强磁场。要进一步完善园区基础设施，加快推进园区道路、供水、供电、通讯、污水处理、标准厂房等配套设施建设，确保项目"签约即落地、落地即可建"。要深化园区体制机制改革，依法依规下放审批权限，推行"一枚印章管审批、一支队伍管执法、一个平台管服务"，让园区真正成为项目集聚的高地、企业发展的沃土。要强化园区产业定位，推动园区差异化、特色化、集聚化发展，避免同质化竞争、低水平重复建设。年内，重点园区基础设施配套率、标准厂房利用率、产业集聚度都要实现新提升，新增"园中园""区中园"承载平台不少于XX个。

四要着力在"政策落实"上求突破。要全面对接国家一揽子增量政策，吃透政策精神、把握政策导向、抢抓政策机遇，做好项目谋划储备和申报争取，力争更多项目纳入国家、省"盘子"。要进一步优化政策供给，市级层面要研究出台支持招商引资、项目建设、企业发展的新一轮政策举措，在土地、税收、规费、融资、人才等方面拿出真金白银。要全面落实惠企政策"免申即享""即申即享""直达快享"，确保符合条件的企业应享尽享、应兑尽兑，让企业第一时间享受政策红利。要持续优化营商环境，深化"放管服"改革，推行重点项目"绿色通道"、并联审批、容缺受理等机制，让项目跑出"加速度"。

五要着力在"对上争取"上求突破。要紧盯国家和省政策导向、资金投向、项目布局，主动对接、积极汇报、靠前服务，争取更多项目列入国家和省支持范围。要加强与央企、省属国企、外资企业的对接合作，围绕重点产业、重点领域，谋划一批强基础、增动能、利长远的重大项目。要积极探索市场化融资模式，规范运用PPP、EOD、REITs等新型融资工具，吸引更多社会资本参与项目建设运营。年内，全市争取国家和省级专项资金、专项资金额度要在去年的基础上稳步增长，市场化融资规模实现新突破。

## 三、强化责任落实，以过硬作风保障秋季攻坚战取得实效

一要压实工作责任。各级党委、政府要把秋季攻坚作为当前经济工作的重中之重，主要负责同志亲自挂帅、亲自调度、亲自协调，分管负责同志靠前指挥、抓在一线。要健全完善市级统筹、部门牵头、区县落实的工作机制，把任务分解到月、细化到周、具体到项目、落实到人。各级领导干部要带头招商、带头接洽、带头推进，以上率下、冲锋在前，形成一级带着一级干、一级做给一级看的良好氛围。

二要强化协同配合。各级各部门要牢固树立"一盘棋"思想，打破部门壁垒、消除条块分割，做到信息共享、资源共用、力量集成。招商部门要强化统筹协调，做好项目对接、签约落地和跟踪服务工作；发改部门要强化项目审批、要素保障和进度管理；工信、商务、自规、住建等部门要主动靠前，做好产业指导、土地供应、规划建设等服务保障；财政、金融部门要创新融资方式、扩大信贷投放，为项目建设提供资金支撑。要健全完善市县联动、部门协同、快速响应的工作机制，做到项目推进到哪里，服务保障就跟进到哪里。

三要严格督查考核。要把秋季攻坚战各项任务纳入年度绩效考核，建立"周报告、月通报、季排名、年总评"机制，对工作进展快、成效显著的给予表彰奖励，对推进不力、进度滞后的严肃追责问责。要整合督查力量，开展多轮次、滚动式督查检查，对重点项目实行全程跟踪、动态管理。要严肃查处项目推进中的不担当、不作为、慢作为、乱作为等问题，坚决打通工作落实"中梗阻"。要充分发挥舆论监督作用，加大对典型经验、创新做法的宣传推广力度，对反面典型公开曝光、形成震慑，营造比学赶超、争先进位的浓厚氛围。

四要严守纪律底线。要严格遵守中央八项规定及实施细则精神，严格执行廉洁自律各项规定，做到依法依规、阳光操作。要强化项目监督和资金监管，严防"形象工程""政绩工程"，严防截留挪用、虚报冒领、套取骗取项目资金。要健全完善项目招投标、资金使用、竣工验收等全过程监督机制，确保每个项目都成为廉洁工程、安全工程、放心工程。

同志们，大干三季度的战鼓已经擂响，决胜下半年的号角已经吹响。全市上下要迅速进入战时状态，拿出决战决胜的勇气、克难攻坚的锐气、事争一流的豪气，咬定目标、苦干实干，奋战三季度、冲刺下半年，坚决打赢秋季招商引资和项目建设攻坚战，以优异成绩迎接党的二十届四中全会胜利召开，为全市经济社会高质量发展、谱写新时代追赶超越新篇章作出新的更大贡献！
