# 在全市优化营商环境暨项目落地推进会上的讲话

**（2026年8月5日）**

同志们：

今天召开全市优化营商环境暨项目落地推进会，主要任务是深入贯彻党中央、国务院关于深化改革、优化营商环境的决策部署，全面落实省委、省政府工作要求，分析当前营商环境和项目建设中存在的突出问题，动员全市上下以更大力度、更实举措、更优作风，推动营商环境再上新台阶、项目建设再提新速度，为完成全年目标任务、推动高质量发展提供坚实支撑。营商环境是发展环境的综合反映，是地区竞争力和软实力的集中体现。一个地方能不能吸引项目、留住企业、集聚要素，关键看营商环境。各地区、各部门要切实把优化营商环境作为推动高质量发展的根本之策，以营商环境的持续优化，激活市场主体的内生动力，催生项目建设的蓬勃活力。

## 一、提高政治站位，深刻认识优化营商环境、加快项目落地的极端重要性

一要充分认识到这是落实党中央决策部署的必然要求。优化营商环境是党中央、国务院作出的重大部署，是推进政府职能转变、激发市场活力的关键之举。要把思想和行动统一到党中央决策部署上来，统一到省委、省政府和市委的工作要求上来，以高度的政治自觉、思想自觉、行动自觉，坚决打好优化营商环境这场硬仗。

二要充分认识到这是应对外部竞争压力的现实需要。当前区域竞争日趋激烈，资本、项目、人才、技术加速流动，哪里环境优、服务好、效率高，资源就往哪里聚集。我们必须正视与先进地区相比在审批效率、服务水平、政策供给等方面存在的差距，知耻而后勇，知不足而奋进，以营商环境的比较优势赢得发展的竞争优势。

三要充分认识到这是稳住经济大盘、完成全年目标的关键支撑。项目是发展的载体，环境是项目的土壤。没有好项目，发展就是无源之水；没有好环境，项目就是无本之木。全市上下必须把项目建设摆在更加突出的位置，把服务保障贯穿到项目谋划、签约、开工、建设、投产的全过程，以高质量项目支撑高质量发展，以高水平服务保障项目高质量落地。

## 二、坚持问题导向，聚焦营商环境短板和项目落地堵点精准发力

一要聚焦审批环节多、流程长的问题，持续深化"放管服"改革。深入推进简政放权，再取消和下放一批行政许可事项，进一步压减不必要的审批环节和前置条件。对重点项目开辟绿色通道，推行并联审批、容缺受理、承诺制办理，确保重点项目审批时限再压缩百分之二十以上。全面推行"一网通办""一窗通办""跨省通办"，让数据多跑路、群众少跑腿，力争年内依申请政务服务事项网上可办率达到百分之百，全程网办率达到百分之九十以上。

二要聚焦政策不透明、获取难的问题，加大惠企政策兑现力度。健全惠企政策统一发布、归集梳理、精准推送机制，依托一体化政务服务平台和"惠企通"等渠道，让企业第一时间知晓政策、用足政策。坚决打通政策落地"最后一公里"，全面推行惠企政策"免申即享""即申即享""直达快享"，确保符合条件的企业应享尽享、应兑尽兑。年内各级惠企资金兑付时限要较上年再缩短百分之三十以上，做到政策红利及时转化为企业红利。

三要聚焦服务不主动、效率低的问题，全面提升服务企业水平。建立领导干部包保联系企业制度，市级领导带头包保重点企业、重点项目，各级干部定期深入一线，现场办公、跟踪服务。完善企业诉求受理、分办、督办、反馈闭环管理机制，做到企业反映问题件件有回音、事事有着落。年内重点企业走访覆盖率达到百分之百，企业合理诉求办结率达到百分之九十八以上。

四要聚焦监管不精准、不规范的问题，创新监管方式提升监管效能。深入推进"双随机、一公开"监管常态化，加强信用监管、智能监管、风险监管，对守法经营企业无事不扰、对违法失信企业利剑高悬。规范执法行为，推行审慎包容执法，明确执法自由裁量基准，坚决杜绝选择性执法、运动式执法、逐利性执法，让企业在法治轨道上安心经营、放手发展。

## 三、强化项目为王，以高质量项目建设支撑经济高质量发展

一要全力抓好项目谋划储备。围绕国家政策导向、产业升级方向和本地资源禀赋，动态谋划储备一批强基础、增动能、利长远的重大项目。聚焦先进装备制造、新材料、新能源、生物医药、数字经济、现代农业、现代服务业等领域，谋划实施一批建链、补链、延链、强链项目。年内全市谋划储备重点项目要达到一定规模，其中产业类项目占比不低于百分之七十，战略性新兴产业项目占比稳步提升。

二要全力加快项目建设进度。对在建项目实行清单化管理、挂图作战，建立"周调度、月通报、季考评"推进机制，及时协调解决用地、用工、资金、审批等难点问题。对未开工项目逐一查明原因，分类施策，推动项目早开工、快建设。对进度滞后的项目，要明确整改时限和责任主体，挂牌督办、跟踪问效。年内省市重点项目开工率、投资完成率要达到预期目标，重点项目实物工作量较上年稳步增长。

三要全力强化招商引资实效。围绕重点产业、重点园区、重点企业，编制产业链招商图谱和目标企业清单，开展精准招商、平台招商、园区招商、以商招商。聚焦京津冀、长三角、粤港澳大湾区等重点区域，紧盯世界500强、国内500强、央企和行业领军企业，主动对接、上门推介，力争年内引进一批高质量项目落户。强化招商项目落地考核，提高合同履约率、资金到位率和项目开工率，坚决防止"数字招商""签约不落地"等问题。

四要全力优化园区承载功能。把园区作为项目落地的主战场，进一步完善园区道路、水电、通讯、环保等基础设施配套，加快建设标准厂房、孵化器、加速器和公共服务平台。深化园区体制机制改革，赋予园区更多管理权限，推动园区提档升级、提质增效。年内重点园区基础设施配套率、标准化厂房利用率、产业集聚度都要实现新提升，真正让园区成为项目集聚的高地、企业发展的沃土。

## 四、强化责任担当，确保优化营商环境和项目落地各项部署落地见效

一要压实工作责任。各级党委、政府要把优化营商环境、推进项目建设摆在突出位置，主要负责同志亲自抓、负总责，分管负责同志具体抓、抓具体，相关部门各司其职、协同配合。健全完善市级统筹、部门牵头、区县落实、基层兜底的工作机制，形成一级抓一级、层层抓落实的强大合力。

二要健全工作机制。完善营商环境评估评价机制，引入第三方评估机构开展常态化监测，推动以评促改、以评促优。健全项目推进协调机制，市级层面定期召开项目调度会、要素保障会、银企对接会，及时解决项目推进中的实际困难。完善督查考核机制，将营商环境和项目建设纳入年度绩效考核，作为干部选拔任用、评先评优的重要依据。

三要严明纪律作风。深入推进干部作风转变，坚决纠治服务企业不担当、不作为、慢作为、乱作为等问题，对推诿扯皮、吃拿卡要、漠视企业合理诉求的行为，发现一起、查处一起、通报一起。健全容错纠错机制，为担当者担当、为负责者负责，营造鼓励创新、宽容失败的良好氛围。

四要营造浓厚氛围。广泛宣传优化营商环境的政策举措、进展成效和典型经验，讲好营商环境的"好故事"，传递服务企业的"正能量"。积极选树一批营商环境优秀案例、项目建设标兵，营造全市上下关心营商环境、参与项目建设、共谋高质量发展的浓厚氛围。

同志们，优化营商环境没有最好、只有更好，加快项目建设永不停步、永无止境。全市上下要进一步统一思想、凝心聚力，以更大的决心、更实的举措、更优的作风，推动营商环境实现根本性提升、项目建设实现突破性进展，为全市经济社会高质量发展、谱写新时代追赶超越新篇章作出新的更大贡献！
