# 申论每日一练 — 2026年7月28日

## 给定材料

当前，全国各地正以"一老一小"为重点，加快构建全龄友好型社区。然而记者调研发现，部分城市在推进过程中仍面临不少现实难题。

N市某街道办负责人坦言，社区嵌入式养老服务中心"建得起却难运营"。该街道投入800万元建成3家日间照料中心，配有康复理疗、营养餐厅、助浴服务等功能，但实际日均服务量不足10人次。运营方反映，60岁以上失能、半失能老人入住率不到15%，原因一是部分子女"怕担责"不愿签托养协议，二是专业护理员月流失率高达38%，薪酬偏低是主因，三是医保长护险覆盖面有限，自费项目老人"用不起"。与此同时，街道60岁以上户籍老人已突破1.2万人，居家养老服务覆盖率虽达92%，但仅有12%的老人能获得上门助餐、助洁、助医"三助"组合服务。

S区在未成年人关爱保护方面也遇到瓶颈。该区建有22个"儿童之家"和17个青少年活动中心，但寒暑假实际到岗志愿者仅占注册人数的31%，心理咨询师持证上岗率不足45%。调研发现，留守儿童、流动儿童心理档案建档率虽达86%，但后续跟踪干预"断档"严重——超过六成的档案在建立后未再更新。社区工作者小李反映，部分家长"谈心色变"，认为心理咨询就是"给孩子贴标签"，宁愿刷短视频也不愿主动求助。

更值得关注的是，"一老一小"服务之间存在明显的协同壁垒——养老机构缺乏儿童活动空间，社区儿童活动中心又缺少适老化设施。两类群体本可在代际互动中相互慰藉，却因场地分设、运营分割而难以共享资源。基层普遍呼吁打通服务壁垒、整合数据平台、培育复合型人才，让社区真正成为"全龄友好"的家园。

## 参考答案

### 第一题：概括问题与对策建议

**主要问题：**

一是社区嵌入式养老"重建轻管"，供需错配突出。设施建成投入大但日均服务量低，失能老人入住率不足15%，子女因担责顾虑签约意愿低，护理员薪酬偏低导致月流失率38%，医保长护险覆盖有限、老人自费负担重。二是未成年人关爱服务"建档断档"。儿童之家、青少年中心利用率不高，志愿者到岗率不足三分之一，心理咨询师持证率低；心理档案建档率虽达86%，但60%以上缺乏后续跟踪干预；家长对心理咨询存在认知误区。三是"一老一小"服务缺乏协同，养老与儿童设施分设、运营分割，代际互动和资源共享机制缺失，平台数据壁垒突出。

**对策建议：**

第一，激活养老服务内生需求。完善长护险扩面与梯度补贴，落实子女"喘息服务"与责任豁免清单，提升护理员薪酬待遇与职业晋升通道，强化医养结合与上门"三助"服务。第二，打通未成年人关爱闭环。加大政府购买心理服务力度，推动心理咨询师下沉社区，常态化开展家长课堂和亲子活动，建立心理档案动态管理机制。第三，统筹"一老一小"服务空间。推动社区综合服务体改造，设置代际共享活动区，培育复合型社工人才，整合智慧养老与儿童关爱数据平台，实现"一网通办、全龄覆盖"。

### 第二题：议论文

# 以"全龄友好"为尺  筑起"一老一小"幸福家园

老吾老以及人之老，幼吾幼以及人之幼，是中华文明绵延千年的伦理底色。当下，我国60岁以上老年人口已超2.8亿，3亿未成年人的身心健康牵动千家万户，"一老一小"问题成为衡量民生温度的关键刻度。然而，养老中心"建得起难运营"、未成年人心理档案"建档易断档难"、两类服务"各管一段"……种种现实困境提醒我们：建设全龄友好型社区，绝非简单叠加设施，而需要系统思维、协同治理与绣花功夫。

**激活养老服务，重塑"居家社区机构相协调"的供给逻辑。** 设施建成不等于服务到位，800万元投入换来日均10人次的窘境，根源在于供需错配与责任分担失衡。一要织密长护险这张"安全网"，扩大覆盖范围，将失能、半失能老人纳入梯度保障，避免"用不起"的服务成为空中楼阁；二要厘清子女赡养责任边界，通过"喘息服务"和责任清单，化解"怕担责"心理，让孝老敬老既合情又合规；三要稳住护理员这支"主力军"，建立与职业等级挂钩的薪酬体系和晋升通道，把月流失率38%的高位降下来。唯有让服务"用得起、有人干、可持续"，居家养老才能真正落地生根。

**闭环未成年人关爱，破解"建档易跟踪难"的治理难题。** 心理档案建档率86%却六成断档，反映出未成年人关爱保护"前热后冷"的体制病灶。破解之道在于"三个下沉"：服务下沉，将政府购买的心理咨询资源向社区倾斜，把持证率拉上来；活动下沉，常态化开展亲子课堂和家长学校，纠偏"贴标签"认知误区；机制下沉，建立心理档案动态管理责任清单，把"建—访—评—转—结"全流程纳入考核。唯有让每份档案都有"下回分解"，才能真正托举孩子的健康成长。

**打破"一老一小"壁垒，构建"全龄共享"的社区生态。** 代际本应是双向滋养的精神纽带，养老机构缺儿童空间、儿童中心缺适老设施，看似无关紧要，实则割裂了社区共同体的情感连接。打破壁垒需"三个统筹"：空间上统筹，推动社区综合服务体改造，设置代际共享活动区，让老人的银发智慧与孩子的童真活力在同一屋檐下相遇；人才上统筹，培育"一专多能"复合型社工，让一名工作者既懂养老又懂护童；数据上统筹，整合智慧养老与儿童关爱信息平台，打通部门壁垒，实现"一网通办"。当老人与孩子在同一片场域相互慰藉，社区才真正有了"家"的味道。

习近平总书记强调："让所有老年人都能老有所养、老有所依、老有所乐、老有所安，让所有孩子都能在党和政府的关怀下健康成长。"建设全龄友好型社区，是这一殷殷嘱托的落地答卷。以系统思维激活服务、以闭环思维呵护成长、以协同思维打破壁垒，把"一老一小"工作做实、做细、做温暖，我们就一定能让夕阳更红、朝阳更灿，让每一位居民都能在社区找到归属感与幸福感，绘就老有颐养、幼有善育的温暖中国。
