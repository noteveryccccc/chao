# 申论每日一练 — 2026年8月5日

## 给定材料

近年来，基层治理中"指尖上的形式主义"与"表格上的留痕主义"问题日益凸显。某省调研数据显示，基层干部平均每人需要承担12条工作线、对应60余个微信工作群、80余个政务APP账号，每周填报各类报表平均耗时18小时，迎接各类检查考核平均9次。"上班时间开会、下班时间填表、周末时间迎检"成为不少乡镇干部的真实写照。

与此同时，数字化技术本应成为基层减负增效的利器，但在实际运行中却出现了"干部跑数据、群众不见面"、"系统层层叠、办事仍繁琐"等异化现象。某县一位社区书记反映："过去入户走访了解民情民意，现在主要任务变成盯着十几个App打卡签到、转发截图、回复点赞。"

基层减负问题已经引起党中央高度重视。2024年中央层面整治形式主义为基层减负专项工作机制会议明确提出，要"让基层干部从繁文缛节、文山会海、迎来送往中解脱出来"。2025年多地开展"指尖减负"专项行动，清理整合了一批僵尸类、考核类政务APP。然而，部分地区仍存在"减了又增"、"明减暗不减"等反弹现象，基层治理"小马拉大车"的结构性矛盾尚未根本解决。

## 作答要求

1. 根据给定材料，概括当前基层减负工作面临的主要问题，并提出对策建议。（不超过400字）
2. 结合材料内容，自选角度，自拟题目，写一篇议论文。（800-1000字）

## 参考答案

### 第一题：概括问题与对策建议

**主要问题：**

一、考核导向偏差，重"痕"不重"绩"。各类检查考核过度依赖报表、截图、签到等留痕材料，基层干部大量时间用于填表迎检，难以集中精力办实事。

二、数字化异化，"指尖"成负担。政务APP、工作群数量泛滥，多头填报、重复打卡、强制转发等问题频发，技术赋能反成形式主义新载体。

三、减负存在反弹，"明减暗不减"现象突出。专项清理过后，部分系统、群组以新名义重新设立，基层负担减而复增。

四、权责失衡，"小马拉大车"。基层承担事项多，但相应资源、编制、权限下放不到位，导致减负治标难治本。

**对策建议：**

一、树立正确政绩观。改进考核方式，将群众满意度、问题解决率等实效指标作为核心考核依据，取消不必要留痕要求。

二、推进数字政务整合。建立政务APP"准入-评估-退出"闭环机制，从源头控制增量，对存量系统分类整合。

三、健全长效治理机制。设立基层减负监测点与举报通道，将减负成效纳入巡视巡察内容，防止问题反弹。

四、深化权责匹配。推动资源、编制、执法权限同步下沉，做到"减上补下、权责对等"，从制度层面破解结构性矛盾。

### 第二题：议论文

**让基层从"指尖之累"回归"足下之路"**

基层是政策落实的"最后一公里"，也是服务群众的"最先一公里"。基层干部的状态，直接关系到人民群众的获得感、幸福感、安全感。然而当下，"指尖上的形式主义"与"表格上的留痕主义"却让许多基层干部困于屏幕、疲于应付，鲜少有时间走村入户、为民解忧。整治形式主义为基层减负，必须标本兼治，让基层干部从"指尖之累"中解脱出来，重回"足下之路"。

基层减负难，根源在于考核导向错位。一些地方把"开会发了文、留了痕"等同于"工作落实了"，将报表、截图、签到作为考核硬指标，却对实际成效、群众感受关注不足。在这种导向下，基层干部不得不把大量精力投入到"做材料"而非"做工作"中。某社区书记坦言"过去入户走访，现在主要盯着十几个App打卡"，这是考核异化导致的现实困境。考核是指挥棒，只有把"群众满意"作为指挥棒，才能让基层干部把心思用在"田间地头"而非"屏幕方寸"。

基层减负难，关键在于数字治理异化。数字技术本是提升治理效能的工具，却在部分场景中变成了加重负担的桎梏。几十个政务APP、几十个微信工作群，层层打卡、级级转发、处处签到，让"数字化"沦为"指尖化"，让"赋能"异化为"负能"。治理数字化不能等同于治理App化，必须从"有没有"转向"好不好用"，从"建系统"转向"用数据"，让技术真正服务于治理效能提升，而非成为新的形式主义外衣。

基层减负难，本质在于权责结构失衡。基层事务千头万绪，但对应的资源、编制、权限并未同步下沉，形成"小马拉大车"的困局。任务层层加码，考核层层加压，而人财物保障层层衰减，减负自然沦为"按下葫芦浮起瓢"的循环。真正为基层减负，必须从制度层面重构权责关系，做到"减上补下、权责对等"，让基层有权有资源、有能力有底气为群众办实事。

基层减负是一项系统工程，不可能一蹴而就，更不可能一劳永逸。必须以正确政绩观为引领，以数字治理规范为抓手，以权责匹配改革为支撑，绵绵用力、久久为功。唯有如此，才能让基层干部从文山会海中解脱出来，从指尖屏幕中解放出来，把更多时间和精力投入到走村入户、服务群众的第一线，让基层治理回归本源、回归实效。

基层减负不是减担当，而是减不必要的负担；不是减责任，而是减错位的形式。让基层干部轻装上阵，才能让基层治理行稳致远；让基层回归"足下之路"，才能让党群干群关系重回"鱼水之情"。这既是基层之盼，也是治理之道，更是新时代推动高质量发展、增进民生福祉的必然要求。
